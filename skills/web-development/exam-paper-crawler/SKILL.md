# 真题试卷搜索归档

## 工作流程

1. 创建归档目录：`~/exams/{语文,数学,英语,学而思,新东方,精锐教育,口算心算,优秀作文}/`
2. **三四五年级优先**，其次一二六年级
3. delegate_task 并行三科搜索 + 教育品牌搜索
4. 每科至少 3 个 subagent 并行
5. 提取内容 → MD 文件 + 答案
6. 持续搜索，不要轻易放弃

## 年级优先级

| 优先级 | 年级 | 原因 |
|--------|------|------|
| 🔴 最高 | 三、四、五年级 | kai哥核心需求 |
| 🟡 中等 | 一、二、六年级 | 补充覆盖 |
| 🟢 低 | 初中预备 | 有余力再做 |

## 教育品牌

学而思 > 新东方 > 精锐教育 > 昂立/四季/乐课力/绿光

## 搜不到的应对

教育网站需要付费/登录时：
- 基于沪教版/统编版大纲自行编写
- 确保每份有题目+答案
- 作文/日记/书信类天然无答案，属正常

## 知识点诊断与查漏补缺模式

当 kai 哥为**具体学生**（如佳乐）定制追补方案时，遵循「先铺资源 → 再诊断 → 再补漏」三步法：

### 三步法

```
Step 1: 铺资源
  ├─ 搜刮各年级知识点清单（道客巴巴 + 贴吧网盘 + 自生成）
  ├─ 每个知识点标注编号（如 M4-1 大数认识、C3-5 阅读理解）
  └─ 配套基础练习题（每题对应一个知识点编号）

Step 2: 诊断
  ├─ 从低于当前年级1-2级开始摸底（D水平四上→从二上计算起步）
  ├─ 做知识点对应练习题，记录对错
  └─ 定位「会」和「不会」的知识点

Step 3: 补漏
  ├─ 不会的知识点 → 翻出口算/试卷对应专项练习
  ├─ 从能做对的题开始建立信心
  └─ 逐步上移难度，直到追上当前年级
```

### 输出格式

生成3类文件：
1. `沪教版X年级-知识点汇总.md` — 该年级语数英知识点清单（表格格式，含编号）
2. `沪教版X年级-基础练习.md` — 知识点对应的基础练习题（每道标注编号）+ 答案
3. `XXX暑假追赶总计划.md` — 学生专属8周计划（含家长须知、每日时间表、资源索引）

### 年级知识点编号规范

| 科目 | 编号前缀 | 示例 |
|------|---------|------|
| 数学 | M | M4-1（四年级第1个知识点） |
| 语文 | C | C3-5（三年级第5个知识点） |
| 英语 | E | E2-3（二年级第3个知识点） |

### 并行搜索策略

三路 delegate_task 并行（每路负责2个平台），降低翻车风险：

```
路1: 小红书 + 知乎 → 文字方法论/家长经验（小红书大概率翻，备用搜狗找知乎URL）
路2: B站 + 抖音 → 视频教程资源（B站✅主力，抖音❌自动放弃）
路3: 微博 + 贴吧 → 真实讨论/资源链接（微博❌自动放弃，贴吧✅主力）
```

每路输出独立 MD，路径 `/mnt/c/Users/admin/Desktop/shanghai-exams/`。

### 贴吧→网盘资源链接跟踪与提取

贴吧中常有用户分享夸克网盘/百度网盘的教育资源链接。发现链接后：

> **🆕 夸克网盘完整操作已独立为 `quark-cloud-drive` 技能。**
> 文件列表提取（免登录）、浏览器登录、保存到网盘、批量下载流程请优先查阅该技能。
> 本技能保留贴吧搜索和链接发现逻辑，下载操作委托给 quark-cloud-drive。

1. **夸克网盘**：用 browser_console + fetch() 调用内部 API 提取文件清单
   ```
   // 获取 stoken
   POST https://drive-pc.quark.cn/1/clouddrive/share/sharepage/token
     body: {pwd_id: '<从分享链接提取>', passcode: ''}
   // 列出文件（pdir_fid 从返回的 list[0].fid 获取）
   GET .../detail?stoken=...&pdir_fid=...&_page=1&_size=50
   ```
2. **百度网盘**：页面可显示文件名但下载需登录。提取码直接拼接 `?pwd=xxxx`
3. **夸克下载受 CORS 限制**，不能直接 curl 下载（API 始终返回 404，即使有有效 Cookie），但可以列出全部文件
4. 提取后输出《资源清单》MD：含文件名、大小、对佳乐的适用度评分（🥇🥈🥉/⭐/⛔）
5. 用 `templates/resource-checklist-template.md` 模板生成资源清单
6. 注意：夸克总合集可能因违规被封（子链接通常还能用）
7. **⚠️ 夸克下载实操（已验证 2026-06-17）**：
   - **免登录 API 列表**：无需 Cookie，直接 urllib 调用 token + detail 端点即可列出所有文件 ✅
   - Cookie + API download endpoint → 始终 404 ❌（浏览器和 curl 均失败，即使已登录）
   - **浏览器登录 + 保存**：用户扫码登录浏览器 → Agent 点击"保存到网盘" → 文件保存到用户夸克网盘
   - 登录态跨会话不持久，每次新会话需重新扫码
   - 完整浏览器登录工作流见 `references/quark-browser-login-workflow.md`
8. **百度网盘**：提取码可绕过浏览限制看到文件名，但下载仍需登录
9. **已知资源分享者**：贴吧「汤姆百宝箱」分享大量沪教版全套资料，可搜索此ID发现更多链接

详见 `references/quark-baidu-cloud-extraction.md`。

## 补基础不拔高方法论

当 kai 哥明确要求为**基础薄弱学生**（D水平/不及格）定制追赶方案时，必须遵循以下原则：

### 核心原则

| # | 原则 | 说明 |
|---|------|------|
| 1 | **从低于当前年级起步** | D水平的四年级学生，数学从二年级计算开始（20以内加减→乘法口诀→万以内加减），不跳跃 |
| 2 | **先建信心再上难度** | 第一周只做能做对的题，全对→奖励。不做任何难题，不碰奥数 |
| 3 | **每天≤2小时** | 绝不超过！贴吧真实案例：D水平孩子全天补课→"学几天就不高兴去了" |
| 4 | **强科弱科分开** | 强科保持即可，弱科每天多分配30分钟 |
| 5 | **只用课本+基础练习册** | 不买拔高教辅。数学=课后练习题，语文=词语听写+朗读，英语=课本单词+跟读 |

### 三科补基础要点

| 科目 | 从哪开始 | 做什么 | 禁止做 |
|------|---------|--------|--------|
| 数学 | 二年级计算 | 口算天天练 + 课本课后题 | 奥数、拔高题、超前学 |
| 语文 | 三年级字词 | 听写词语 + 朗读课文 + 造句 | 阅读理解技巧、作文框架 |
| 英语 | 26个字母 | 认读+听写字母 → 课本单词 → 简单句跟读 | 语法规则、句型转换 |

### D水平学生暑假追赶时间线

```
第1周：只做计算 + 字母
  ├─ 每天3组口算（20题/组，从20以内加减法开始）
  ├─ 全对→奖励，建立"我能行"的信心
  └─ 语文英语先不动，让孩子感觉"今天只学一样"

第2-3周：加入轻量语文英语
  ├─ 数学保持口算 + 开始翻四上课本（只看不做难题）
  ├─ 语文：每天朗读5分钟 + 听写3个词语
  └─ 英语：每天认读3个字母 + 1个单词

第4-6周：逐步加量
  ├─ 口算加量（30题/组 × 3组）
  ├─ 做课本课后练习（只做基础题，标*的跳过）
  └─ 语文听写加到5个词，英语加到3个单词

第7-8周：综合复习
  ├─ 把前面做错的题重做一遍
  ├─ 四上课本通读一遍（不要求全会，有个印象即可）
  └─ 准备开学
```

### 输出格式

当用户明确说了"帮XXX补基础"时，附加一份**《XXX暑假追赶计划》**MD，含：
- 当前水平分析（1段）
- 三科分别的起点和终点（各1段）
- 每日时间表（表格）
- 家长须知（5条避坑指南）
- 推荐免费资源（B站UP主 + 可打印练习）

## 原创练习材料生成（基于特级教师方法论）

当用户需要的是"让孩子练起来"的实操材料，而非理论/试卷时：

1. **阅读理解练习**：基于丁有宽读写结合法，自创短文 + 题目 + 答案
   - 每篇文体轮换：记叙文→写景→写人→寓言→叙事→写物→科普→散文→童话→应用文
   - 每篇5题，覆盖6大必考题型（概括、解词、赏析、情感、联系实际、含义）
   - 每题标注分值，附详细参考答案 + 错题分析区

2. **写作练习卡**：基于武凤霞/乔亚梦分年级专题体系
   - 每专题含：任务说明 → 方法步骤 → 范文片段 → 自查清单
   - 附万能开头/结尾模板 + 急救技巧（五感凑字法等）

3. **每日训练计划**：基于于永正五重教学法
   - 周一阅读→周二写作→周三精读→周四作文→周五泛读→周末综合
   - 含家长配合要点 + 参考书单

4. **输出PDF**：使用 `chinese-pdf-generation` 技能生成可打印PDF
   - 前提：`apt-get install fonts-noto-cjk` + `pip install weasyprint`

### 原创力文档搜索技巧（关键）

**URL 直接带查询参数无效**：`?q=关键词` 会被重定向到首页，必须通过表单交互。

1. `browser_navigate` 到 `https://max.book118.com/`

4. 搜索结果页预览包含大量内容（短文全文+题目），用 `browser_console` 提取：

   // 提取搜索结果预览文本
   document.querySelectorAll('.search-result-item li, li').forEach(el => {
     const text = el.textContent.trim();
     if (text.includes('阅读理解') && text.length > 200) { /* 提取 */ }
   });
   ```

## 扩展用法：知识点×全网资源批量匹配搜索 ⭐ NEW

当 kai 哥要求**把已有的知识点清单（如334点）与全网夸克网盘/道客巴巴/B站资源做逐一匹配**时，遵循此流程。

### 前置条件

1. 已有完整知识点清单文件（如 `小学1-5年级语数外知识点全览.md`，含 M/C/E 编号）
2. 目标：找到每个知识点的对应教学资源链接

### Step 1：分类生成搜索关键词

将知识点按学科+年级+能力层分组，每组提炼2-3个搜索关键词。关键原则：
- **贴吧搜夸克链接**：用 `pan.quark.cn` + 通用学科词（不要品牌词！触发安全验证）
- **道客巴巴搜文档**：用沪教版+年级+学科，品牌词会被过滤（见 pitfall）
- **B站搜视频**：用学科+年级+沪教版，品牌词不限

关键词模板见 `references/bulk-search-keyword-template.md`。

### Step 2：三平台并行搜索

使用 delegate_task 三路并行（2026-06-17 验证可行）：

```
路1: B站 → browser + console提取视频列表（学而思/新东方/沪教版）
路2: 道客巴巴 → browser + snapshot提取文档预览（通用词绕过品牌过滤）
路3: 贴吧 → 搜 pan.quark.cn 夸克链接（仅1-2次搜索，用最关键的关键词）
```

### Step 3：提取 + 汇总 + 匹配

1. 贴吧结果：提取所有 pan.quark.cn 链接 + 上下文描述

```

### 夸克网盘：链接可发现，下载需手动

- API 可列出文件列表（需 Cookie） ✅
- API 下载始终 404 ❌
- 唯一可行：用户手动在夸克APP打开链接 → "保存到网盘" → 下载
- 报告末尾附操作指南即可

### Pitfalls

1. **贴吧首搜是关键**：新会话的首1-2次搜索可能成功，必须用最有价值的关键词一锤定音
2. **道客巴巴品牌词过滤**：学而思/新东方在道客巴巴搜不到，用通用词替代
3. **夸克链接 ≠ 可下载**：找到链接只是第一步，实际下载需用户手动操作
4. **B站UP主注销**：部分资源UP主为"账号已注销"，链接可能随时失效，优先收藏活跃UP主

## 扩展用法：学生诊断与查漏补缺

当需要帮学生（如D水平）精准定位知识漏洞时，不用盲目刷题：

### 诊断原则
- **先诊断，再开药**：必须先测出漏洞在哪里，再针对性出练习
- **数学用年级线性诊断**：知识点严格依赖前序（不会乘法不可能做除法），从一年级逐级测
- **语文用能力分层诊断**：6层（拼音→识字→词语→句子→阅读→写作），从底层测起
- **英语用能力分层诊断**：6层（字母→音标→词汇→句型→语法→阅读），D水平很可能字母都不过关

### 诊断表结构
```
数学：120题，按 S1-1 ~ S4-43 编号，每知识点一题
语文：38题，分6层，每层独立过关
英语：44题，分6层，从26个字母认读开始
```

### 拼音英语混淆专项

当学生存在拼音与英语字母发音混淆（中高年级常见遗留问题）时，生成14天速成方案：
- 三条铁律：拼音英语不同天学、红蓝双色笔区分、先灭拼音再攻英语
- 核心工具：红蓝切换卡片游戏（每天5分钟）+ 易混字母对比表
- 四年级学生2周可搞定（认知力远超一年级）

> 详见：`references/pinyin-english-remediation.md`

### 查漏补缺流程
1. 生成诊断表（数学按年级、语英按分层）→ 打印PDF
2. 学生逐题做，✅会 ❌不会
3. 找到第一个大面积❌的层/年级 → 断层位置
4. 从断层处生成针对性练习题
5. 补完一层再往上一层

> 参考文件：`references/diagnosis-templates.md`

### MD→DOCX转换脚本

使用 python-docx 自动转换。核心脚本模式（存为 `/tmp/convert_md_to_docx.py` 复用）：

```python
from docx import Document
from docx.shared import Pt, Cm
from docx.oxml.ns import qn
import re, os

def set_font(run, name='宋体', size=11, bold=False):
    run.font.size = Pt(size)
    run.bold = bold
    rPr = run._element.get_or_add_rPr()
    rFonts = rPr.find(qn('w:rFonts'))
    if rFonts is None:
        rFonts = __import__('lxml.etree', fromlist=['etree']).SubElement(rPr, qn('w:rFonts'))
    rFonts.set(qn('w:eastAsia'), name)
    rFonts.set(qn('w:ascii'), name)

# 正文宋体11pt，标题黑体，A4页面，2.5cm边距
# 支持 #/##/### 标题、**加粗**、- 列表、| 表格
```
