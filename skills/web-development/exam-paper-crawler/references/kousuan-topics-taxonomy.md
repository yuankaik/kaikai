# 口算专题分类与生成指南

## 完整专题分类（1-6年级）

### 一年级（上）
- 10以内加减法
- 20以内加减法

### 一年级（下）
- 100以内加减法（一）：不进位、不退位
- 100以内加减法（二）：进位、退位

### 二年级（上）
- 九九乘法口诀口算
- 表内除法口算

### 二年级（下）
- 100以内加减乘除混合口算

### 三年级（上）
- 万以内加减法口算
- 多位数乘一位数口算
- 时间换算口算（时/分/秒互化、加减、比较）
- 长度/重量单位换算（km/m/dm/cm/mm、t/kg/g）

### 三年级（下）
- 两位数乘两位数口算
- 除数是一位数的除法口算
- 递等式口算（脱式计算，两步运算含优先级）
- 找规律口算（数列、图形符号、算式规律）

### 四年级（上）
- 大数读写口算（亿以内读写、组成、改写、近似数）
- 四则混合运算（含括号/无括号、两步/三步）

### 四年级（下）
- 小数加减法口算
- 简便运算巧算（交换律/结合律/分配律、减法/除法性质）

### 五年级（上）
- 小数乘除法口算
- 小数与分数互化口算
- 简易方程口算（一步/两步/含括号）

### 五年级（下）
- 分数加减法口算
- 分数乘除法混合口算

### 六年级
- 分数乘除法口算
- 百分数口算与比例速算

### 通用/跨年级
- 口算竞赛题（限时50题，含巧算+找规律）
- 竖式口算练习（加减乘除竖式，3-4年级适用）
- 速算技巧汇编

## 生成工作流

### 步骤1：检查已有
```python
from hermes_tools import search_files
existing = search_files("*口算*", target="files", path="/home/adminkaikai/shanghai-exams")
# 或检查桌面：
desktop_existing = search_files("*口算*", target="files", path="/mnt/c/Users/admin/Desktop")
```

### 步骤2：对照专题分类找缺口
将已有文件与上述分类对照，列出缺失专题，优先三四五年级。

### 步骤3：道客巴巴搜格式参考
```python
browser_navigate("https://www.doc88.com/")
browser_type(ref=搜索框, text="三年级口算练习题")
browser_click(ref=搜文档按钮)
# 从快照提取题目格式、难度、题型分布
```

### 步骤4：批量生成 MD
用 `execute_code` 一次生成多个文件（比逐个 write_file 快得多）：
```python
from hermes_tools import write_file
import os
desktop = "/mnt/c/Users/admin/Desktop/口算补充练习"
os.makedirs(desktop, exist_ok=True)

# 每个文件结构：
# - 标题 + 年级信息
# - 分题型（一/二/三/四/五），每部分标注分值
# - 题量：40-100题/文件
# - 参考答案：每题有答案，巧算/递等式需展示过程
# - 保存为 MD 格式（用户可能要求转 DOCX）
```

### 每份文件的格式模板
```markdown
# [年级] [专题名称]

## 一、[题型名]（每题X分，共X分）
1. 题目...
...

## 参考答案
### 一、
1. 答案...
```

## 难度把控
- 三、四年级：每题2-3分，题量80-100
- 五、六年级：每题2-3分，题量50-80
- 竞赛题：每题2分（基础）+ 5分（巧算），共50题
- 竖式练习：每题2-3分，共40题左右

## 验证
生成后检查：
1. 每题都有答案
2. 递等式/巧算有解题过程
3. 单位换算答案单位正确
4. 分数答案化为最简
