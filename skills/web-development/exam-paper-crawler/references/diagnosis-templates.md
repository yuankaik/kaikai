# 学生诊断模板

## 诊断结构对比

| | 数学 | 语文 | 英语 |
|---|:---:|:---:|:---:|
| 结构 | 年级线性 | 能力分层 | 能力分层 |
| 层级 | 一上→四下 共8段 | 拼音→识字→词语→句子→阅读→写作(6层) | 字母→音标→词汇→句型→语法→阅读(6层) |
| 题数 | 120 | 38 | 44 |
| 编号 | S1-1~S4-43 | C-P1~C-WR4 | E-L1~E-R5 |
| 过关 | 按年级段 | 一层全✅才进入下一层 | 同语文 |

## 数学编号体系
- S1 = 一年级 (S1-1~S1-20)
- S2 = 二年级 (S2-1~S2-24)
- S3 = 三年级 (S3-1~S3-33)
- S4 = 四年级 (S4-1~S4-43)

## 语文分层
1. 拼音 (C-P1~C-P6)：声母、韵母、整体认读、声调、拼写
2. 识字写字 (C-W1~C-W8)：各年级必会字、形近字、多音字、部首
3. 词语 (C-V1~C-V7)：近反义词、搭配、ABB式、成语、解释
4. 句子 (C-S1~C-S8)：把字句、缩句、扩句、病句、关联词、修辞
5. 阅读理解 (C-R1~C-R5)：找信息、找细节、理解、概括、推测
6. 写作 (C-WR1~C-WR4)：完整句→连贯→观察描写→短文

## 英语分层
1. 字母 (E-L1~E-L5)：大小写认读、配对、书写、顺序
2. 音标 (E-P1~E-P4)：元音、开闭音节、拼读
3. 词汇 (E-V1~E-V10)：数字、颜色、动物、身体、食物、家人、学校、动作、天气、反义词
4. 句型 (E-S1~E-S10)：I am/This is/I like/I can/Can you/What is/How many/What color/Do you/I have
5. 语法 (E-G1~E-G10)：be动词、have/has、There be、like/likes、现在进行时、冠词、复数、代词、比较级、三单
6. 阅读 (E-R1~E-R5)：简短短文理解

## 诊断后处理
1. 统计每层/段✅率
2. 找到第一个正确率<70%的层 → 断层位置
3. 从断层处生成专项练习题
4. 每补完一个知识点用原诊断题复查
