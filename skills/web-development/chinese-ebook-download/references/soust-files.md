## 下载常见问题

0. **Python session 下载（小文件，推荐）**：见 `references/soust-python-workflow.md`。用 `requests.Session()` 登录+搜索+批量下载，速度远快于浏览器操作，无 session 丢失问题。**仅适用于 <3MB 文件；大文件会超时。**

1. **大文件下载（>5MB）：Python→curl 桥接**：搜书网带宽仅 ~10KB/s，40MB 文件需 1h+。Python `execute_code` 300s 上限必定超时。解决方法：Python 登录+搜索（快）→ 导出 Netscape cookie → `terminal(background=True, notify_on_complete=True)` 跑 curl 后台下载（不限时）。详见 SKILL.md "大文件下载：Python→curl 桥接" 节。

2. **下载中断**：大文件在 Browserbase 浏览器中超时，表现为 .crdownload 未完成就消失。可用手机浏览器下载替代。
3. **迅雷 .xltd 文件**：用户用迅雷下载的 .xltd 文件，去掉 .xltd 后缀即为完整文件（非损坏）。验证：`file 文件名.epub`。
4. **Session丢失**：browser_navigate 到不同 URL 时 cookie 可能丢失。同页面内用 browser_console + fetch 可保持 session。
5. **重复下载扣分**：系统记录为"已下载"的文件，即使下载失败再次下载也不退积分。
6. **登录页面 body 清空**：偶尔 browser_navigate 登录页后 body 为空，刷新即可恢复。
