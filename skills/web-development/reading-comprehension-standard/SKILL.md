# 阅读理解练习题质量标准

适用：上海小学四年级 | 用于审核网络爬取或自生成的阅读练习

## 六维标准

### 1. 短文标准（按文本类型）

**记叙文：**
- **字数**：350—550字（中文汉字计数，不含标点）
- **原创性**：非教材课文，自主创作或改编
- **体裁**：记叙文/写人/写景/叙事/散文/书信优先；寓言、科普酌情

**说明文（新增）：**
- **字数**：350—500字
- **主题范围**：动物习性、自然现象、科技发明、人体奥秘、植物生长、天文地理、环保、中国传统文化事物
- **原创性**：基于真实科学知识创作，数据准确
- **语言**：清晰平实，有明确说明方法（列数字/作比较/举例子/打比方）
- **结构**：总分总或总分结构，每段有明确说明要点

**非连续性文本（新增）：**
- **类型**：公交时刻表、超市促销海报、图书馆规则、课程表、药品说明书、天气预报、运动会日程、菜单营养成分表、景区票价表、地铁线路图
- **信息密度**：至少包含3-5个可查询的独立信息点
- **真实性**：数据和格式模拟真实场景
- **复杂度**：需要比较、计算或条件判断，不是直接照抄

### 2. 主题要求
必须贴近以下四类之一：
- 校园生活
- 家庭亲情
- 日常生活
- 成长感悟

**排除**：纯寓言、纯科普说明文、脱离儿童生活的话题

### 3. 难度定位
中等偏基础——80%的四年级学生应能独立完成。用词不超纲，句式不复杂。

### 4. 题型结构

**记叙文（5题）：**

| 题号 | 题型 | 说明 | 示例问法 |
|------|------|------|---------|
| Q1 | 信息提取题 | 从文中直接找到答案 | "根据文章内容填空""文中写了哪些……" |
| Q2 | 词语理解题 | 理解词语在文中的意思 | "……是什么意思？""文中指什么？" |
| Q3 | 原因题 | 分析因果关系 | "为什么……""……的原因是什么？" |
| Q4 | 句子理解题 | 理解含义深刻的句子 | "这句话是什么意思？""文中画线句子……" |
| Q5 | 人物品质或中心题 | 概括人物品质或文章中心 | "……是一个怎样的人？""文章告诉我们什么道理？" |

**说明文（4-5题）：**

| 题号 | 题型 | 说明 | 示例问法 |
|------|------|------|---------|
| Q1 | 信息提取题 | 从文中直接找到事实信息 | "……有什么特点？""……分为哪几类？" |
| Q2 | 词语/概念理解 | 理解科学术语在文中的意思 | "……在文中指什么？""……是什么意思？" |
| Q3 | 说明方法判断 | 识别并分析说明方法的作用 | "划线句用了什么说明方法？这样写有什么好处？" |
| Q4 | 内容概括/推理 | 概括段落大意或推理隐含信息 | "根据文章，为什么……？" |
| Q5 | 联系实际/评价 | 将科学知识与生活联系 | "读了文章，你学到了什么？""生活中还有类似的例子吗？" |

**非连续性文本（4-5题）：**

| 题号 | 题型 | 说明 | 示例问法 |
|------|------|------|---------|
| Q1 | 直接信息查找 | 从文本中定位单一信息 | "……多少钱？""……几点开始？" |
| Q2 | 信息比较 | 比较多条信息得出结论 | "哪一天更便宜？""哪个更划算？" |
| Q3 | 条件判断/计算 | 根据条件筛选或计算 | "如果……一共需要多少钱？" |
| Q4 | 推理应用 | 根据信息做出决策或建议 | "你会选择哪个？为什么？""如果……应该怎么办？" |
| Q5 | 信息整合/评价 | 综合多条信息得出结论 | "从材料中你能得出什么结论？"

### 5. 答案格式（每题必须包含4要素）

```
Q1. [题型：信息提取题]
标准答案：（完整答案文本）
段落依据：第X自然段
评分点：（每个得分点及分值）
常见错因：[标签1] [标签2]
```

**常见错因标签库**：
- 审题不清 / 信息找错段落 / 回答不完整
- 望文生义 / 脱离上下文 / 解释太笼统
- 因果倒置 / 只写结果不写原因 / 遗漏关键信息
- 理解停留在字面 / 没联系上下文 / 表达不清
- 概括太宽泛 / 找不到中心句 / 细节代替品质

### 6. 配套输出

**家长批改提示**：
```
📝 家长批改要点：
1. 重点检查Q___（指出最易错的题）
2. 如果孩子做错Q___，建议引导方法：___
3. 本篇核心能力：___（如"提取关键信息""理解人物情感"等）
```

**孩子重写任务**：
```
🔄 孩子重写任务：
错Q___→重新做这道题，用"答案模板"写
错Q___→回原文第___段再读一遍，用笔画出关键句后再答
错3题以上→全文重读+全卷重做
```

## 合规率计算

| 维度 | 权重 | 满分条件 |
|------|------|---------|
| 字数350-550 | 25% | 中文汉字在范围内 |
| 主题四选一 | 20% | 校园/家庭/生活/成长 |
| 难度适中 | 10% | 中等偏基础 |
| 5类题型 | 25% | 信息提取+词语+原因+句子+品质中心 |
| 答案格式 | 20% | 含段落定位+评分点+错因标签 |

≥80% = 合规，可直接使用。60-79% = 需修改。＜60% = 需重写。
