# 60天阅读训练计划模板

## 总览

| 阶段 | 天数 | 内容 | 日题量 |
|------|------|------|--------|
| 基础适应期 | Day 1-7 | 短文阅读，每天2篇 | 10题/天 |
| 专项复练期 | Day 8-60 | 按错因类型专项训练 | 10题/天 |

## 阶段一：基础适应期（Day 1-7）

每天2篇短文，难度中等偏基础。文体按天轮换：
- Day 1: 记叙文×2
- Day 2: 写人+写景
- Day 3: 叙事+生活小事
- Day 4: 校园故事×2
- Day 5: 家庭亲情+成长感悟
- Day 6: 写物+散文
- Day 7: 综合复习（4篇任选2篇重做）

## 阶段二：错因专项复练（Day 8-60）

家长在阶段一结束后统计错因标签。根据最高频错因，从以下专项库中连续练习：

### 错因 → 专项映射

| 高频错因标签 | 专项训练 | 建议天数 |
|-------------|---------|---------|
| 信息找错段落 / 回答不完整 | 信息提取强化 | 连续3天 |
| 脱离上下文 / 解释太笼统 | 词语理解强化 | 连续3天 |
| 因果倒置 / 只写结果不写原因 | 因果关系强化 | 连续3天 |
| 理解停留在字面 / 表达不清 | 句子深层理解 | 连续3天 |
| 概括太宽泛 / 细节代替品质 | 人物品质+中心概括 | 连续3天 |
| 审题不清 / 答非所问 | 审题专项 | 连续2天 |
| 答案太短 / 用词单一 | 完整句表达 | 连续3天 |

### 专项复练后 → 回头测原错题 → 新错因出现 → 再专项练

循环直到错因标签消失或稳定在低频率。

## 每日文件格式

```markdown
# Day N：[阶段名称]

## 篇1：[标题]
### 阅读短文
[350-550字]

### 题目
Q1. [信息提取题]（XX分）
Q2. [词语理解题]（XX分）
Q3. [原因题]（XX分）
Q4. [句子理解题]（XX分）
Q5. [品质/中心题]（XX分）

### 参考答案
**Q1. [题型标签]**
- 标准答案：（完整文本）
- 段落依据：第X自然段
- 评分点：（得分点列表）
- 常见错因：[标签]

...(Q2-Q5同理)...

### 📝 家长批改提示
1. 重点检查 Q_（最易错题号）
2. 如果做错 Q_，引导方法：______
3. 本篇核心能力：______

### 🔄 孩子重写任务
- 错Q_ → 重新做，用答案模板写
- 错Q_ → 回原文第_段再读，画关键句后重答
- 错3题以上 → 全文重读+全卷重做
```

## 主题分配（保证多样性）

120篇主题分布：
- 校园生活：30篇
- 家庭亲情：25篇
- 日常生活：25篇
- 成长感悟：25篇
- 自然观察：10篇
- 其他（书信、日记等）：5篇
