# 圈画阅读法 + 五大答题模板

## 适用场景

佳乐（或类似四五年级学生）阅读理解做了很多篇但正确率不提升时使用。核心诊断：不是量不够，是方法没对。

## 圈画阅读法（做题前 2 分钟）

读文章时拿笔做三件事：

| 标记 | 用什么 | 圈什么 |
|------|--------|--------|
| 🔴 红笔圈 | 红笔 | 人名 / 地名 / 时间 / 数字 |
| 🔵 蓝笔画 | 蓝笔 | 反复出现的词 / 关键词 |
| 〰️ 波浪线 | 铅笔 | 每段第一句和最后一句 |

**原理：** 读完一遍就忘了 → 圈画 = 把文章变成"地图"，回头找答案不费劲。90% 的答案就在圈画内容里。

## 五大题型模板

看到题目先判断是哪一种，套对应公式：

### ① 概括题
- **标志：** "这篇短文讲了什么？""用一句话概括……"
- **公式：** 谁 + 做了什么 + 结果怎样
- **例：** 小明（谁）在雨天帮老奶奶撑伞（做了什么），老奶奶安全到家（结果）

### ② 词语题
- **标志：** "这个词好在哪里？""XX是什么意思？"
- **公式：** 本义是…… + 文中指…… + 写出了……
- **例：** "小心翼翼"本义是非常小心，文中指小明轻轻捧着小鸟，写出了他对小鸟的爱护

### ③ 句子题
- **标志：** "这句话有什么含义？""谈谈你的理解"
- **公式：** 表面说…… + 实际表达了……
- **例：** 这句话表面写花儿开了，实际表达了春天到来的喜悦心情

### ④ 作用题
- **标志：** "为什么这样写？""XX有什么作用？"
- **公式：** 为了突出…… + 让读者感受到……
- **例：** 写天气很冷是为了突出妈妈在寒风中等待的辛苦，让读者感受到母爱的伟大

### ⑤ 道理题
- **标志：** "你明白了什么？""给你什么启示？"
- **公式：** 文中……可以看出…… + 生活中我们也应该……
- **例：** 从文中蚂蚁搬食物可以看出团结就是力量，生活中我们也应该学会合作

## 做题三步流程

1. 读文章时 → 圈画（红笔圈人名时间、蓝笔画关键词、波浪线标首尾句）
2. 看题目 → 判断是哪种题型（概括/词语/句子/作用/道理）
3. 写答案 → 套模板 + 回文中找你圈画的地方抄关键词

**秘诀：** 90% 的答案就在圈画内容里！不要自己编，去文中找！

## 错题三问（比做新题更重要）

每道错题花 30 秒：
1. 这道题在考什么？→ 对一下上面的五种题型
2. 答案在文中哪里？→ 用荧光笔标出原文位置
3. 标准答案比我多了什么？→ 把漏掉的关键词抄在旁边

## 使用建议

- 做成一张打印卡压在桌垫下，做题前看一遍
- 两周后肌肉记忆形成即可扔掉
- 宁可做 1 篇 + 反思，不要做 5 篇不反思
