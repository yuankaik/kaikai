# 中文信息搜索

## 触发条件
- 搜中文长尾词：地址、弄堂号、小区名、地名、政务公告、本地政策
- 必应/百度搜索结果跑偏、返回无关内容、触发验证码
- 查拆迁/征收/旧改/规划等政务信息

## 搜索引擎选型（实测结论）

中文长尾信息（尤其地址/地名/小区）搜索优先级：

| 引擎 | 适用 | 坑 |
|------|------|-----|
| **搜狗** sogou.com/web | 中文长尾词、地址匹配最好 | 结果链接是 `/link?url=` 跳转，需跟一次跳转拿真实 URL |
| **360** so.com/s | 同上，且对"XX弄"这类精确地址匹配好 | 跳转链接 `/link?m=` 可能 400 |
| 必应 cn.bing.com | 英文、通用 | 对中文地址分词失灵（"四川北路1515弄"→拆成"四川"返回四川省）；无头浏览器环境结果被污染 |
| 百度 | 国内百科/知道 | 无头浏览器/自动化访问触发验证码（wappass 安全验证） |
| DuckDuckGo | 英文 | 国内网络连接被重置 |

**关键技巧**：用 `curl`/`requests` 带真实 UA 直接打搜索引擎，比无头浏览器更可靠（浏览器会被降级/触发验证码）。requests 直接拿 HTML 后用正则提 `<h3>` 标题即可，搜狗/360 反爬比必应/百度宽松。

```python
# 搜狗示例
r = requests.get('https://www.sogou.com/web', params={'query': q},
                 headers={'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/120.0'})
# 结果在 <h3><a href=...>标题</a></h3>
```

## 政务/本地信息权威渠道（拆迁、征收、规划、政策）

按可靠度排序：

| 渠道 | 怎么查 | 说明 |
|------|--------|------|
| **12345 市民热线** | 电话 12345 或"随申办"APP | 最直接，能问到具体地址是否列入计划 |
| **区政府官网** | 如虹口 shhk.gov.cn → 政府信息公开 → 房屋征收栏目 | 征收决定/范围/补偿方案在此公示 |
| **属地街道/居委会** | 直接去问 | 居民第一手消息，有动迁最先知道 |
| **权威媒体** | 上观新闻、澎湃新闻 | 上海旧改地块动态报道及时 |
| "上海征收"公众号 | 微信搜 | 征收类官方信息聚合 |

**政府官网站内搜索注意**：很多区政府官网的站内搜索是第三方服务（如 mayabot.com），是 JS hash 路由 + 后端 API，curl 抓不到结果、逆向成本高。优先用上面的权威渠道，或直接搜"XX区政府官网 + 关键词"让搜索引擎带你找到公示页。

## 上海旧改/征收的领域知识（查拆迁前先知道）

1. **按"街坊"地块编号推进**，不是按具体弄堂号——搜"XX弄 拆迁"常搜不到，要先搞清楚它属于哪个街坊（如"虹口19街坊"），再查那个街坊的征收公告。
2. **历史风貌建筑走"风貌保护更新/修缮"而非拆迁**——百年里弄、风貌建筑限高，政策上不鼓励大拆大建（参考今潮8弄模式）。
3. **网上能搜到的多是居民问答**（百度知道、360问答），官方征收必以"XX街坊房屋征收决定"形式在区政府官网公示；没搜到政府官网公告 = 大概率还没正式征收。
4. 疑似征收范围的短视频/自媒体门牌列举（抖音等）不可当依据，需政府官网核实。
