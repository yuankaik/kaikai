# 转录文字→每日学习卡片 降维转换技法

## 适用场景
将B站转写得到的教育视频文字（通常面向初中/中考水平），简化为小学生能用的每日背诵卡片。

## 核心原则
- **降维不降质**：保留原视频的框架和核心观点，但用小学生能懂的语言和例子
- **每天1条，不超过2分钟**：量少才能坚持
- **不比不对不考**：卡片是"读一读想一想"，不是背诵任务

## 转换流程

### 1. 快速扫读提取主题
```python
# 用关键词扫描提取核心观点
keywords = ['意识', '方法', '技巧', '记住', '重点', '核心', '关键', '第一步', '三个', '两个']
# → 定位到视频的核心论点段落
```

### 2. 判断难度适配
- 中考审题技巧 → 简化为"圈出题目关键词"
- "悬念意识" → 简化为"开头让人好奇"
- "细节描写" → 简化为"写具体，不写抽象"
- "首尾呼应" → 简化为"结尾回到题目"

### 3. 卡片格式（固定模板）
```markdown
## Day N | 日期 | 第X周

**原则（一句话）**

> 解释（用对比法）

❌ 不好的写法：（反面例子）
✅ 好的写法：（正面例子）

📝 今天的练习：（可操作的小任务）
```

### 4. 例子必须来自小学生生活
- ❌ "中考作文审题" → ✅ "圈出题目里最重要的词"
- ❌ "扶老奶奶过马路" → ✅ "体育课跑400米岔气了"
- ❌ "悬念意识" → ✅ "用「突然」「没想到」开头"

## 案例：梓墨说语文 → 佳乐14张卡片

| 视频原主题（中考） | 简化后（小学生） |
|-------------------|-----------------|
| 写好故事：悬念意识 | 开头让人好奇 |
| 写好故事：细节意识 | 写具体，不写抽象 |
| 写好故事：起伏意识 | 结尾要有变化 |
| 选素材：真实 | 写真事，不编故事 |
| 选素材：有意义 | 选「长了记性」的事 |
| 审题：抓关键词 | 先圈题目关键词 |
| 10次精改：反复修改 | 好作文是改出来的 |
| 非连续文本：信息分层 | 一段只写一件事 |
| 写好故事：对话 | 至少写一句「谁说」 |
| 审题：先想后写 | 写之前先想30秒 |
| 选素材：避俗 | 少用「然后」，换连接词 |
| 写好故事：数字 | 用数字代替模糊词 |
| 写好故事：开头技巧 | 开头不要「有一天」 |
| 审题+首尾呼应 | 结尾回到题目 |

## 家长卷 vs 学生卷
- **学生卷**：极简，每天1条原则+1个例子，2分钟读完
- **家长卷**：每条配来源说明+引导提问，方便家长晚饭后和孩子聊
