## 技巧提炼策略

对于技能类课程（数学/语法/写作），转录后的处理分两步：
1. **人工读懂**：通读转录稿，提取核心技巧名称和口诀
2. **程序化命题**：每个技巧写问题生成函数，参数化控制题量、难度

```python
# 技巧→生成函数的映射模式
def gen_cou_10(count=20):
    """凑整法：个位凑十，其他位凑九"""
    qs = []
    for _ in range(count):
        ones_a = random.randint(0, 9)
        a = tens_a * 10 + ones_a
        b = (9 - tens_a) * 10 + (10 - ones_a)
        qs.append(f"{a} + {b} = ")
    return qs
```

## 40天课程设计原则

- 每3天引入一个新技巧，中间穿插复习
- 每天40题左右，含TIPS行+专项练习+综合复习
- D等学生优先基础技巧(前6讲)，特殊技巧(后12讲)作调味
- 后20天对接沪教版5年级：小数乘除→分数加减→方程
- 最后一周综合复习全技巧

## 技术要点

- 问题生成用独立函数，避免PLAN数组里混合参数格式导致bug
- `gen_mult_fixed(fixed, other_min, other_max, count)` 清晰区分固定乘数和范围乘法
- DOCX输出用2列表格，宋体11pt，TIPS行灰色小字
- 答案用Python eval自动计算（分数除外，保留原式）
