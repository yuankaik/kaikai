# 转录文字→每日练习题 生成技法

## 适用场景
将技能类课程（数学技巧、语法规则、写作方法）的转录文字，转化为可打印的每日练习题。

## 通用流水线

```
转录文字 → 提取技巧/规则 → 设计问题生成函数 → 编排课程计划 → 批量生成MD → DOCX
```

## 技巧提取模式

从转录稿中按以下结构提取：

| 技巧元素 | 提取方法 | 示例 |
|----------|----------|------|
| 技巧名称 | 找「XX法」「XX技巧」「口诀」 | 凑整法、商不变 |
| 核心口诀 | 找「口诀就是」「记住」后的短句 | 个位凑十，其他位凑九 |
| 适用条件 | 找「什么时候用」「适用于」 | 看到25就想4 |
| 示例算式 | 正则匹配 `\d+[×÷+-]\d+` | 25×12=25×4×3=300 |

## 问题生成函数设计

每个技巧对应一个生成函数，参数化控制：

```python
def gen_fixed_mult(fixed, other_min, other_max, count):
    """固定乘数×范围，如：25 × [4..99]"""
    qs = []
    for _ in range(count):
        other = random.randint(other_min, other_max)
        qs.append(f"{fixed} × {other} = ")
    return qs
```

关键原则：
- 输入校验：other_min < other_max，count > 0
- 去重：大规模生成时检查重复题
- 答案可算：能用eval自动算的优先，分数/特殊格式留原式

## 课程编排原则

- 每3天引入新技巧，中间穿插复习
- 每天40题左右（15分钟量）
- 每份含 TIPS行(技巧提示) + 专项练习 + 综合复习
- D等学生优先基础技巧，高难技巧作调味

## 应用到佳乐暑假

口算板块（已实现）：
- 源MD → 口算心算-速算技巧版/ (40个MD)
- DOCX → 口算生成/学生卷_速算技巧版/ (40+40个DOCX)
- 合并 → 第1~8周/学生卷/Day01~40-全部练习.docx

每日板块格式：
```
🔢 口算（15分钟）
├── TIPS: 巧算核心=让数字变好算！
├── 一、凑十加法（15题）
├── 二、万以内加减（15题）
└── 三、乘法口诀（10题）
```

## 其他可应用此模式的课程类型

- 语法规则课 → 每日语法练习
- 写作技巧课 → 每日句式仿写
- 阅读理解课 → 每日篇章+问题
