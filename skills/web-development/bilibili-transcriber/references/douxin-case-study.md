# 窦昕/豆神大语文 — B站视频转写案例

## 背景
窦昕（豆神）是知名语文教育品牌，B站有大量搬运其付费课程的超长合集视频。

## 关键发现：多分P合集

### 问题演变
1. **第一轮**：搜到21个视频，全是500+小时合集 → 误判为"不可处理"
2. **第二轮**：选取最短的5个（223-598分钟）尝试转写
3. **第三轮**：前2个成功，后3个音频只有2-8MB → 发现是"只下了P1"
4. **第四轮**：检查 `info['data']['pages']` → 发现每个视频有8-30个分P！

### 修正后的处理方式
```python
# 错误做法（最初）
cid = info['data']['cid']  # → 只有P1！

# 正确做法
pages = info['data']['pages']
for p in pages:
    cid = p['cid']  # 每P独立cid
    # 每个P是独立的小课（3-43分钟）
```

## 实际案例

| 合集 | 分P数 | 单P时长 | 内容示例 |
|------|:---:|------|------|
| 万能作文课 | 8P | 33-43分 | P1写人秘籍, P2陌生人, P3一波三折, P4写长写细... |
| 阅读理解基础 | 16P | 5-27分 | P1三步拿下, P2赏字分层, P3析作者... |
| 小学满分作文 | 19P | 3-8分 | P1写出范文, P2什么是定格, P3主要描写对象... |
| 初中阅读理解 | 30P | 3-26分 | P1三步拿下, P2赏字, P3析作者... |

## 对佳乐的匹配度

- **万能作文课 P1-P5** ✅ 最对口（写人/写事/写景，小学核心）
- **阅读理解基础 P1-P5** ✅ 方法通用
- **小学满分作文前5P** ✅ "定格写作"技巧适合小学生
- **初中阅读理解** ⚠️ 偏深，暂不入

## 技术细节

### 时长格式兼容
```python
# duration 可能是 int 或 "MM:SS" 或 "HHH:MM"
if isinstance(dur, str) and ':' in dur:
    parts = dur.split(':')
    dur_sec = int(parts[-2]) * 60 + int(parts[-1])
    if len(parts) > 2:
        dur_sec += int(parts[0]) * 3600
```

### 音频完整性校验
正常音频约 0.5MB/分钟。2MB的音频要对应598分钟 → 明显不完整。阈值：`actual_mb < expected_mb * 0.3`。
