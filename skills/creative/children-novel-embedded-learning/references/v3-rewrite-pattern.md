# V3 Rewrite Pattern: Reader-Feedback-Driven Overhaul

When the target reader rejects the story, don't tweak — rebuild with clear diagnostics.
Developed from 深海钓徒 V2→V3 rewrite (袁佳乐, 10-year-old sports boy).

## Phase 1: Diagnose

Gather ALL complaints before planning. Common signals from a 10-year-old male reader:

| Signal | Meaning |
|--------|---------|
| "英语太多" | English feels like homework. Cut from target % to <3%. |
| "没意思" | Event density too low. Single-event chapters feel 过家家. |
| "幼稚" | Too cute, too safe. BOSS names sound made up, animal companions feel like mascots. |
| "不爽" | Protagonist is reactive, wins are close, bystanders aren't shocked. |
| "不够搞笑" | Comedy is wordplay or knowledge-based. Need physical comedy + deadpan snark. |
| "不像写给我的" | Book name feels textbook-ish. Dedication feels generic. |

## Phase 2: Rebuild the Foundation

Before rewriting a single chapter:

1. **Rename**: Cool factor first. 字海钓徒 → 深海钓徒. "字" = textbook. "深海" = adventure.
2. **Re-protagonist**: From passive student to 嘴硬型小学生战神. Catchphrase after action, not before.
3. **Re-BOSS**: Replace invented names with real game names (王牌钓手). Arcade rhythm, not storybook.
4. **Re-comedy**: Physical > Deadpan > Misunderstanding. No wordplay. No knowledge gags.
5. **Re-education**: English from 17% to <3%. Weapon, not lesson.

## Phase 3: The Five-Point 爆笑 Upgrade

When the draft has "爽文骨架" but isn't fully "爽文+爆笑爽文":

1. **爽点前置**: Chapter 1 hook stronger. Protagonist can't write fake essays → writes real things in deep sea → instant power.
2. **加缺点**: Protagonist needs "小学生式" flaws: hates essays but won't admit it, first reaction to BOSS is "can I skip this", mouth/脑 split.
3. **中段加笑点**: Chapters 5-14 tend to go epic/serious. Inject humor WITHOUT removing epic moments. Bystanders destroy atmosphere at sacred moments.
4. **现实闭环**: The opening conflict MUST close. Same essay, same teacher — but protagonist wins differently.
5. **统一反复梗**: Every recurring joke must thread through every chapter. Audit gaps >2 chapters.

## Phase 4: The Per-Chapter Template

Every chapter rewritten to include:

```
现实痛点 → 深海怪物映射 → 主角嘴硬吐槽 → 离谱破局 → 围观震惊 → 记录更新 → 现实反击
```

## Phase 5: Audit

Run the 10-dimension full-book audit. Fix criticals first: timeline, missing skills, unresolved threads.

## Key Lessons from 佳乐

- "英语太多" was the #1 complaint. New target: <3%.
- "受着呗" goes AFTER the action, not before. Post-action = cool. Pre-action = nervous.
- BOSS shouldn't die. BOSS should lose dignity. That's funnier.
- Every partner needs their own agenda. No cute mascots.
- The reader IS the protagonist. Book name and dedication must feel personal.
