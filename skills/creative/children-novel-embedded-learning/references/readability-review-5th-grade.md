# 五年级可读性审查工作流

针对上海小学五年级（~10-11岁，识字量~2500，沪教版）读者的全书审读方法。

## Trigger

用户要求"以五年级水平审视全文"或"看看阅读有没有困难"时触发。

## 四维扫描 (P1-P4)

### P1: 词汇难度

用 Python regex 扫描全文，标记潜在的难词：

```python
import re

hard_patterns = [
    # 抽象概念
    r'退化|萎缩|收缩|扩张|辐射|穿透|真空',
    r'博弈|逻辑|概率|公式|认证|体系|机制',
    r'保守|妥协|战略|战术|谈判|外交',
    # 成人/正式用语
    r'前所未有|史无前例|匪夷所思',
    r'固然|尚且|宁[可愿]|何尝',
    r'格局|维度|境界|层次',
    r'窒息|淹没|吞噬|侵蚀',
    r'尊严|荣誉|羞愧|羞辱|窘迫',
    # 文学/书面
    r'徘徊|彷徨|踌躇',
    r'凝[视望]|瞥见|瞟|瞪',
    r'兀自|依旧|依然如故',
    # 商业/经济
    r'营销|品牌|资产|负债|利润|成本',
    r'投资|回报|估值|溢价|折扣',
    r'注册|专利|版权|授权',
]

for pat in hard_patterns:
    matches = re.findall(pat, clean_text)
    if matches:
        # 获取首次出现的上下文判断是否需要改
        ...
```

**判断标准**：词是否被上下文自解释？
- "畏光"→后文"半夜被手机屏幕晃到眼睛" → **不改**
- "朝贡体系"→无上下文解释 → **建议改**
- 河童英文长句 → 孩子可跳过，核心信息中文已覆盖 → **不改**

### P2: 句式复杂度

```python
sentences = re.split(r'[。！？\n]{1,2}', clean_text)
lengths = [len(s.strip()) for s in sentences if len(s.strip()) > 5]
avg_len = sum(lengths) / len(lengths)
long_count = sum(1 for l in lengths if l > 100)
```

**五年级基准**：
- 平均句长 <20字 → 优秀
- 超过100字的句子 <100个 → 可接受
- 超过300字的句子需逐条审查（大部分是河童英文笔记，可跳过）

**脑子多层自嘲**：4-5层笑话嵌套可能追丢。需确认朗读时是否放慢。

### P3: 逻辑/情节

手动通读检查：
- 每章是否有清晰的事件（进入→遭遇→解决→升级）
- 伏笔是否回收（列出关键伏笔，grep确认每个都有后续）
- "受着呗"使用时机是否合理（强化→接受→传递，层层递进）
- 配角是否每章都有存在感（比目鱼/吴薯片/河童不能缺席>2章）

### P4: 幽默适龄

笑点分类评估（按五年级get到概率排序）：

1. **100% 命中**：BOSS的搞笑缺点、李老登对比、比目鱼表情包、"我妈是走人"
2. **90-95%**：吴薯片商业线、河童斗笠被砸统计、嘴vs脑内讧
3. **70%**："复活节彩蛋"等需要游戏/文化背景的梗

## 核心原则

1. **不自解释的才改**。50%+难词被上下文自然解释，不需要动。
2. **河童英文是bonus track**。孩子跳过去不影响理解，不要因为"英文太多"而删。
3. **改法需"同字数替换"**。见 SKILL.md pitfalls 中的 layout-preserving number fixes。
4. **建议≠命令**。给用户选择权，标注哪些"不改也不影响阅读"。

### P5: 英文占比诊断（如适用）

当全书包含英文内容时，运行字符级占比分析：

```python
import re

cn_chars = len(re.findall(r'[\u4e00-\u9fff]', clean))
en_chars = len(re.findall(r'[a-zA-Z]', clean))

# English word count (3+ letters)
eng_words = re.findall(r'\b[a-zA-Z]{3,}\b', clean.lower())
word_freq = {}
for w in eng_words:
    word_freq[w] = word_freq.get(w, 0) + 1

# Source breakdown
kappa_entries = len(re.findall(r'"[A-Z][^"]{30,}"', clean))
sword_lines = [l for l in lines if 'Sword' in l and re.search(r'[a-zA-Z]{10,}', l)]
pure_eng_lines = sum(1 for l in lines if re.search(r'[a-zA-Z]', l.strip()) and not re.search(r'[\u4e00-\u9fff]', l.strip()))

# Character ratio
ratio = en_chars / max(cn_chars + en_chars, 1) * 100
word_ratio = len(eng_words) / max(cn_chars, 1) * 100
print(f"英文字符占中英合计: {ratio:.1f}%")
print(f"英文单词 ÷ 中文字符: {word_ratio:.1f}%")
print(f"纯英文行: {pure_eng_lines}")
```

**输出**：
- 英文字符占中英合计的百分比（含空格则为20-25%，不含约15-18%）
- 英文单词 ÷ 中文字符的单词比（目标 <7%，《受着呗》实际 7.0%）
- 英文来源拆解：河童笔记本 / Sword对白 / 石壁涂鸦 / 叙事文
- 河童英文长条目数量（128段/14K字符为《受着呗》基准）

**判断标准**：
- 英文单词比 <5%：完全无压力，河童笔记是bonus track
- 5-10%：可接受，但需确认核心情节中文全覆盖
- >10%：考虑精简非河童笔记的英文

关键结论格式："跳过英文不影响理解的比例 = 约93%"。河童英文长条目不计入阅读障碍——孩子扫一眼跳过即可，核心信息中文全部重复。不要因为"英文太多"而建议删英文内容。英文是风格选择，不是缺陷。

### P6: 三科教育价值分析（如适用）

当用户问"这本书对学习有帮助吗"时，从语文阅读、语文写作、英语三角度量化分析：

**语文阅读（阅读理解考点匹配）**：
- 提取多线叙事数量（grep 各线关键词）
- 统计情感变化标记（怕/紧张/担心→接受/骄傲的过渡）
- 统计比喻/形象表达密度
- 对照沪教版5年级四大考点：概括主要内容、体会思想感情、理解含义深刻句子、分析人物形象

**语文写作（可模仿的写作模板）**：
- 统计嘴/脑子对位结构数量（心理描写范例）
- 统计短句密度（<15字短句数量 — 对字丑写得慢的学生友好）
- 识别重复callback模式（同一句话在不同情绪下的变化）
- 识别BOSS=缺点比喻模式（抽象概念具象化）

**英语单词（牛津课本对照）**：
- 提取所有英文单词，与牛津1-5年级词汇表对照
- 分类：已学词（巩固价值）、超纲词（故事浸入式习得）
- Top 15 已学高频词 + Top 15 超纲高频词
- 结论：已学巩固占比 vs 自然浸入占比

**输出格式**：
三段并行分析，每段含数据表格和一句话结论。最后给三科加权评分表（★★★★★），权重：阅读50%/写作30%/英语20%。
