# External Diagnostic Analysis Pattern

When the user provides an external analysis (like 建议.MD), treat it as a diagnostic report, not a to-do list.

## Processing Rules

1. **Read the full analysis and extract:**
   - Component percentages (爽文%, 搞笑%, 无厘头%, 燃%, 学校线%)
   - Structure breakdown (前期/中期/终局/番外 ratios)
   - Character screen-time distribution
   - Gap identification (what's low, what's missing)
   - Comparison scores (vs reference works like 一念永恒)

2. **Map gaps to concrete actions:**
   - "误会链太短" → Add rumor-to-plot chain reactions
   - "装逼不自知不够" → Add misinterpretation moments where bystanders overestimate protagonist
   - "中段笑点密度低" → Inject破坏气氛 gags into middle chapters
   - "长篇厚度不足" → Acknowledge this is a length-class difference, not a quality issue

3. **Prioritize by impact:**
   - High: Gaps that affect reader experience (humor density, pacing)
   - Medium: Enhancement opportunities (rumor chains, character depth)
   - Low: Structural differences that are inherent to the format (5万字 vs 长篇)

4. **Apply targeted fixes, not rewrites:**
   - Each fix should be 1-3 lines inserted at the right spot
   - Never restructure the whole book based on a percentage breakdown
   - The analysis confirms direction — it rarely demands a U-turn

## Key Metrics Reference (from V3 final audit)

For a 5万字 children's 爽文 targeting ~85% 一念永恒 similarity:

| Component | Healthy Range | V3 Actual |
|-----------|--------------|-----------|
| 爽文主线 | 30-40% | 35% |
| 超级搞笑 | 20-30% | 24% |
| 轻喜剧/吐槽 | 15-20% | 18% |
| 无厘头 | 10-15% | 14% |
| 燃/史诗 | 8-12% | 9% |
| 现实学校线 | 5-8% | 6% |

No single component should dominate. The mix IS the flavor — 爽文骨架 (35%) + 搞笑血肉 (42%) + 无厘头调味 (14%) + 燃点收束 (9%).
