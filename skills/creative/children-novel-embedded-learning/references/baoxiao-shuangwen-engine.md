# 爆笑爽文 Comedy Engine

When the user says "还不够爽" or "不够搞笑", the problem isn't plot — it's the comedy engine.
This reference captures the complete system developed for 深海钓徒 V3 爆笑版.

## Per-Chapter Comedy Template

Every chapter must follow this sequence:

```
现实痛点 → 深海怪物映射 → 佳乐嘴硬吐槽 → 离谱破局 → 围观震惊 → 河童记录 → 现实反击
```

Not every beat needs equal weight, but ALL must be present.

## 离谱破局 (Absurd Victory Pattern)

BOSSes are NOT defeated by power. They're defeated by absurd logic that makes them lose dignity.

| BOSS | Absurd Weakness | Victory Method |
|------|----------------|----------------|
| 鬼蝠魟 | Mouth too wide | 佳乐 swims INSIDE, explodes from within |
| 大王乌贼 | Can't count past 4 | Write "六" → squid counts tentacles → ties self in knots |
| 沧龙 | Photosensitivity (lived in dark too long) | Open 永夜伞 → light blinds it → sneezes from iron dust |
| 凯撒火龙 | Old volcano, bad aim (火力衰退) | Fire misses 60% →佳乐 compares to broken school microwave |
| 深渊帝王龙 | Carries everyone's failed writing | Write one word that ends ALL unfinished sentences |

**Rule: BOSS doesn't die. BOSS loses dignity. That's funnier.**

## 围观震惊系统 (Bystander Shock System)

After EVERY BOSS victory, mandatory reactions from ALL present companions:

| Character | Fixed Reaction | Comedy Function |
|-----------|---------------|-----------------|
| 河童 | Notebook entry (funny observation) | Official record of absurdity |
| Goldie | Drops/loses/finds a potato chip | Running gag — chips at dramatic moments |
| 比目鱼 | Makes an inexplicable facial expression | Visual comedy — two eyes on same side |
| Sword | 剑尖往左偏二度 (his laugh) | Deadpan speed commentary |
| Octo (after Ch5) | Prepares to monetize the battle | Capitalism in crisis moments |
| 大母龟 (after Ch7) | Tail-launched rock hits河童's hat | Physical comedy — always河童 |

## Recurring Joke System (Running Gags)

Must thread through EVERY chapter. Track frequency.

| Joke | Frequency | Evolution |
|------|-----------|-----------|
| 受着呗 | 2-3x per chapter | Said AFTER dominant action, not before |
| 河童's broken English | 1-2x per chapter | Mistranslations get progressively worse |
| Goldie's薯片 drops | 1x per chapter | Eventually learns to bite down during battle |
| 比目鱼黏竿尖 | Every scene | Develops opinions about battles, grows light spot |
| 锅形光纹炸锅 | Every training attempt | Causes: arm numb, chips→popcorn, Octo sells "explosion insurance" |

| 河童's斗笠 damage | Accumulates | 刀痕→凹痕→焦痕→被石头砸→被火龙烧 |
| 李老登 callback | 1x per chapter | Different angle each time, never repeat comparison |

## BOSS Absurdity Archetypes

Every major BOSS should have ONE mundane, embarrassing weakness:

1. **Math deficiency**: Can't count own body parts (大王乌贼)
2. **Old age problems**: Photosensitivity, bad eyesight, sneezing (沧龙)
3. **Equipment failure**: Powers declining due to age (凯撒火龙)
4. **Existential burden**: Carrying everyone else's failures (深渊帝王龙)
5. **Communication gap**: Can only respond, never initiate (海神)

## 嘴硬型小学生战神 (Protagonist Voice)

佳乐's internal split:

- **嘴 (mouth)**: "受着呗" — casual, dismissive, unbothered
- **脑子 (brain)**: "完了完了完了" — panicking internally
- **First reaction to any BOSS**: "好大 → 打不过 → 能不能跳过 → 受着呗"
- **Treats battles as nuisances**: "这东西能不能跳过？" "它都张嘴了我不进去显得不礼貌"

## Humor Injection for Epic Sections

When chapters trend too serious (永夜伞 dungeon, 海神 dialogue):

- Goldie drops薯片 into the sacred light
- 河童's notebook paper becomes transparent, writing overlaps
- 比目鱼 thinks海神 is talking to IT personally, starts posing
- Octo tries to sell limited-edition merchandise mid-battle
- One name on the sacred list has an embarrassing backstory (bad handwriting, wrong character, gave up because of a typo)

## Reality Payoff (现实闭环)

The ending MUST return to the opening conflict:

- Chapter 1: 佳乐 can't write essay "我的梦想"
- Final chapter: Same essay, same teacher — but writes about catching the sea god
- Teacher: "主题不积极" → gives 78. Someone claps.
- 佳乐 flips paper over, writes "续" on the back.
- Bookend: from "can't write" to "can't stop writing"
