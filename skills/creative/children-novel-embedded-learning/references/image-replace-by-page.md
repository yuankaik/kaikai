# 按PDF页码替换插图

当用户说"替换P16/P79/P108的图"时，页码指打印版PDF的页码。生成脚本按顺序映射插图：
第1个 `[插图:]` → 1.png，第2个 → 2.png，以此类推。

## 映射方法

```python
import re

with open("全文终稿.md") as f:
    text = f.read()

captions = re.findall(r'\[插图: ([^\]]+)\]', text)
for i, cap in enumerate(captions, 1):
    print(f"插图{i}: {cap[:60]}")
```

输出示例（来自《受着呗》）：

| 插图编号 | 对应PDF页码 | 场景 |
|----------|-------------|------|
| 5 | P16 | 鬼蝠魟 |
| 6 | P18 | 鬼蝠魟炸裂 |
| 17 | P79 | 海神·碧蓝新星海蛞蝓 |
| 18 | P89 | 写十二个名字 |
| 21 | P108 | 李老登批卷 |

对照用户的描述（"P16正文已进入鬼蝠魟前奏"）匹配即可。

## 替换操作

```bash
ILLUSTR="插画文件夹路径"
# 备份
cp "$ILLUSTR/5.png" "$ILLUSTR/5.png.bak"
# 替换
cp 用户提供的新图 "$ILLUSTR/5.png"
```

替换后重新生成PDF，版面不受影响（只要新图尺寸接近原图）。

## 注意事项

- 用户可能直接把新图放到插画文件夹里，命名为 P16.png / P79.png / P108.png
- 不要改生成脚本，只替换对应编号的图片文件
- 备份原图（.bak）方便回退
