# 主角弱点重定向模式

当用户反馈"佳乐的短板是X不是Y"时，需要在全书范围内精确替换，同时不改变其他任何设定。

## 触发信号

- 用户说"佳乐最不擅长的是XXX，不是XXX"
- 用户提供了具体分数/能力对比（如"作文能及格，阅读理解一直挂"）
- 通常伴随"保持全文不要楼歪了"的警告

## 操作步骤

1. **全局搜索所有旧弱点的提及**——用 `search_files` 或 `grep` 找到"作文"、"写不出"、"白纸"等所有相关词
2. **识别需要改的章节节点**——Ch1开局描写、Ch2深海能力对比、中间内心独白、Ch17课堂结尾
3. **逐个替换**——保持句子结构不变，只换弱点指向
4. **注意篇幅分配**——如果原本的"作文78分结尾"占了大篇幅，新结论也要有对等的情绪重量

## 本次案例：作文→阅读理解

| 位置 | 旧 | 新 |
|------|-----|-----|
| Ch1开局 | "一写作文变植物人" | "一做阅读理解变植物人" |
| Ch1细节 | 作文白纸 | "四个选项，划了C改B...永远选错" |
| Ch1对比 | "作文能写，交了，及格" | 保留（证明作文不是短板） |
| Ch1痛点句 | "写不出假话" | "阅读理解考的永远是你读到了什么——是'作者想表达什么'" |
| Ch2深海对比 | "写过最长的东西是周记" | "这辈子最怕的事是阅读理解——但'比目鱼'不是选项。是事实。" |
| Ch17结尾 | 作文78分，老师卡住 | 作文75分平淡过 + 阅读理解68分、小对勾 |
| Ch17新结尾 | 无 | "不符合标准答案。但……有自己的理解。" |

## 关键原则

- **不要只是搜索替换**——每个位置的替换逻辑不同
- **保留被"降级"的旧弱点的正面描写**——如果作文变成能及格，就要删掉"作文白纸"式的否定
- **新结尾必须比旧结尾更细**——阅读理解的反杀不是大爽，是克制型爽点，要写得更有层次
- **深海能力对比要重建**——原来的对比是"作文写不出→写字成绝杀"，需要改成"阅读理解不及格→看见事实就能写对"
