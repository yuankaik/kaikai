# 爽文+爆笑儿童小说创作引擎

> 基于《深海钓徒》V3 开发实战。对标《一念永恒》白小纯式爆笑爽文。

---

## 一、每章节奏模板

```
现实痛点 → 深海怪物映射 → 主角嘴硬吐槽 → 离谱破局 → 围观震惊 → 河童记录 → 现实反击
```

## 二、主角人设配方

| 维度 | 设定 |
|------|------|
| 嘴 | "受着呗"——永远嘴硬，永远说最狠的话 |
| 脑子 | "完了完了完了"——内心实时崩溃 |
| 第一反应 | "能不能跳过"——不热血，怕麻烦 |
| 强项 | 体育/游泳/投篮——身体天赋异禀 |
| 弱项 | 作文/背诵——学业痛点绑定现实 |
| 口头禅 | 短、狠、每次出现加重量 |

## 三、围观群众震惊系统

每场BOSS战后固定出场：

| 角色 | 固定反应 | 升级方向 |
|------|----------|----------|
| 河童 | 笔记本记录（短狠准，1-2句） | 记录越来越离谱 |
| 吴薯片(Goldie) | 薯片掉落 | 从黑帮转型纪念品事业部 |
| 比目鱼 | 无法解读的表情 | 从吉祥物变成移动表情包 |
| Sword | 剑尖往左偏二度=笑 | 死鱼眼式震惊 |
| 朱八爪(Octo) | Trust me→Trust me? | 假货商人被动变诚实 |

## 四、BOSS战设计三原则

1. **不是打赢——是赢得离谱**。用小学生逻辑把BOSS尊严打碎。
2. **BOSS必须心理崩溃**。乌贼数不到四自己打结、沧龙眼睛退化打喷嚏、火龙火力衰退瞄不准。
3. **每次胜利引发社会后果**。"自从乌贼被六打败以后，暗礁迷宫所有鱼数到六之前都会犹豫。"

## 五、三大传播系统

### 传闻系统
每章开头一句深海流言，越来越离谱：
"传闻他不走门，只走胃。"
"传闻他让沧龙让路了。沧龙。让路。"

### 商业化系统
吴薯片打完BOSS立刻卖周边："乌贼自绑绳""火龙火焰烤薯片"。

### 误会链
主角随手做→现场震惊→外界传成另一种→传到下章更离谱。

## 六、现实锚点

- 作文写不出来→深海一写就破纪录
- 罚抄→深渊帝王龙身上全是写坏的字
- 结尾回到教室，用真实表达赢一次（不是打脸老师，是找到自己想写的东西）

## 七、名字安全原则

- 不用真实人名（老师、同学）
- 用外号代替真名
- 老师只保留外号，不出现全名
- 同学映射虚化为半虚构

## 八、幽默密度控制

| 位置 | 密度 |
|------|------|
| 前5章 | 每章3+笑点，建立节奏 |
| 中段(6-14) | 史诗场面必须有人破坏气氛 |
| 结尾(15-17) | 现实闭环+情感收束，笑点不减 |
| 番外 | 纯彩蛋，不混入主线 |

## 九、禁忌

- 后半段不能变成纯燃文（爽文≠燃文，爽文=爽+笑）
- 河童英文笔记每次最多两句，最后一句必须是笑点
- 李老登对照频率：只在高关联章节使用，不要每章都提
- 隐藏章标记【番外】，正章结束加"全书正章完"
