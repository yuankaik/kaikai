## 一、ISO13485 vs GMP（最常被遗漏的考点）

行业从业者原话：**"我们做器械的，ISO13485是命根子"**。

| | GMP | ISO13485 |
|---|---|---|
| 是什么 | 中国法规《医疗器械生产质量管理规范》 | 国际标准（质量管理体系） |
| 谁要求 | 国家药监局 NMPA **强制** | 国际通行，出口/外企必备 |
| 违了怎样 | 飞检不过 → 停产、罚款、吊销 | 认证不过 → 丢订单、丢市场 |
| 关系 | 互为映射；GMP 是 13485 在中国法规化的落地 | "全球通用尺子" |

相关体系还有 **QMSR**（美）、**MDSAP**（五国）、**QSR 820**（美旧标）。
面试能说出这几个的关系是加分项，但不必深挖。

**用户只有 ISO9001/14001/45001 时的标准话术**：
> "我现有经验是 ISO 三体系，13485 和 GMP 是我的学习重点——
> 但**体系审核的底层逻辑是通的：文件受控、记录可溯、责任到人、变更留痕**。"

### ISO13485 落地合规逻辑（面试可能被问）
- 核心不在于"有没有证书"，而在于**质量管理体系是否符合专项标准要求**
- 常见不符合项集中在：文件编制、内审、整改、迎检准备
- 医疗器械一次性用品、植入类、无菌类 → 清洁验证/灭菌确认/洁净区监测 SOP 须**按产品定制**
- 有源器械 → 电气安全检验规程、软件确认程序须按技术要求定制

## 二、仓库管理的"地基"概念（回答"仓库管理重点是什么"必须用到）

### 账卡物三一致
```
账 = 系统账（SAP/ERP 里的数字）
卡 = 物料卡（挂在货架上的卡片）
物 = 实物（仓库里真实存在的货）
三者必须一致，不一致就是差异
```
这是"仓库管理重点在哪"的**标准答案第一个词**。

### 5S / 五定 / 目视化（高频题，用现有经历套）
```
5S   = 整理 整顿 清扫 清洁 素养
五定 = 定区 定点 定位 定责 定管
目视化 = 用颜色/标识让任何人一眼看懂状态
```
套用映射（把普通仓储经历翻译成 5S 语言）：
- ABC分类、高频物料放易取位 → **定点定位**
- 颜色标签区分物料状态 → **目视化**
- 每岗至少2名合格人员、组长负责制 → **定责定管**

### 优质答法骨架（"仓库管理的重点"）
```
① 地基：账卡物三一致
② 实质：管住货物从进仓到出仓期间每一次实物/库位/数量/属性/状态的变化
③ 延伸：人员 + 跨部门协同
```
第②层是拉开层次的关键——它证明答者懂**过程控制**而非只会盘点。

## 三、GMP 核心考点补充（考点表之外）

| 考点 | 具体要求 |
|---|---|
| **记录保存3年** | 温湿度等记录保存期限；药监局随时查、飞检会翻 |
| **划改** | 记录写错：划掉（保留可辨认）+ 旁边写正确 + 签名 + 日期。**不得涂改、禁用修正液** |
| **洁净区传递** | 脱外包 → 传递窗/缓冲间 → 消毒 → 记录；**人与物料分通道** |
| **静压差** | 洁净区对非洁净区 ≥10Pa 正压（2025新版GMP新增强制量化条款） |
| **五区** | 待验(黄) / 合格(绿) / 不合格(红) / 退货 / 召回；**物理隔离**，不能只靠系统状态 |
| **UDI** | DI（产品标识，固定）+ PI（生产标识，含批号/序列号/效期）；GS1 标准；需与医保编码、院内物资编码做**外部映射** |
| **飞检** | 不预先通知，"最怕飞检人员突然推门"——现场**随时可查**，不是临时准备 |

### 2026 时效政策
- **新版《医疗器械生产质量管理规范》2026年11月施行**，内容增加超一半
- 明显变化：**更强调信息化系统要求**；静态压差等更细化的量化条款
- **UDI 全面实施**（2026）→ 仓储是**最关键追溯节点**（出厂→入院必经），
  WMS 必须具备 UDI 码的扫描、存储、追溯功能
- **趋势**：从"人管"转向"系统管"；信息化/数字化能力从加分项变成必需项

> 💡 这个政策节点是**求职窗口**：政策刚变，企业正缺懂行的人。
> 有数字化/自研系统经验的候选人可以此打"反杀题"（"我懂新规+我有动手能力"）。

## 四、国企（烟草/央企）方向

### 上海烟草集团 —— 结论：社招基本关闭
| 路径 | 可行性 | 说明 |
|---|---|---|
| 校招（应届生） | ❌ | 主力渠道，编制型用工：年度定编→校招一次性补员→全年不招 |
| 社招（公开） | ⚠️ | 公告极少，多为"高层次技术人才"（博士/行业专家门槛） |
| 劳务/第三方外包 | ✅ | 唯一现实入口，但身份是外包，待遇与正式工差 2-3 倍，岗位多为操作类 |

**隐性硬门槛**：年龄 35 周岁以下（部分放宽40）——不写在公告上但实际卡人。

### 一个被广泛误解的事实（核实过）
网上传"考高分也进不了烟草"。**实际录用名单**：
```
2022年  → 大批"大专"学历，院校集中上海电机学院、上海出版印刷高专
2025年  → 名校约25%（62人），普通院校约53%（130人）
2026年  → TOP20 院校中上海本地占11所、61个名额，前五全是本地院校
```
**真相：不唯名校，大量招本地院校（含大专）。真正看重 ① 上海本地 ② 稳定性 ③ 专业对口。**

⚠️ 但这些优势只在**校招入口**生效。社招走不通，优势用不上。

### 值得盯的公司（比集团总部机会大）
```
上海烟草储运公司          ← 仓储物流主业，最对口
上海烟草包装印刷有限公司
上海白玉兰烟草材料有限公司
上海各区烟草糖酒有限公司   ← 各区都有，岗位分散
上海新型烟草制品研究院
```
**只信官网**：`www.sh.tobacco.com.cn`（人才招聘栏）、`www.tobacco.gov.cn`（人事信息）。
网上"年薪30万"说法基本都是中介/自媒体编的，不可信。

### 国企 vs 外企简历的取舍差异
| | 国企/烟草 | 外企/医械 |
|---|---|---|
| 要看到 | 本地+专业对口+**稳定(长任职)**+安全生产+ISO体系 | 成果量化、体系深度、英语、管理幅度 |
| 不要看到 | 太"跳"的东西（自研AI系统、跨领域项目） | — |
| 逻辑 | 要"稳妥可靠、待得住" | 要"有业绩、能带团队" |

⚠️ 同一份简历投两个方向要**分别改造**，不要通用。

## 六、方向排序思路（帮用户选方向时用）

### 6.1 五维度筛选（2026-09 修正版，**取代旧的四维度卡点法**）

⚠️ **重要教训**：早期版本只按"硬门槛 vs 强项匹配度"排序，结果把**汽车**排到了
备选第一（理由"同行迁移最顺"）。用户直接纠正：**"汽车行业在国内已经夕阳产业了"**。
只算"能不能进"、不算"这行业还值不值得进"，会推荐用户跳进一条下沉的船。

**必须五维度同时看**（前两条是新增，缺了就出错）：

```
① 行业景气度（新增·最重要）  → 增量市场还是存量血战？
② 年龄友善度（新增）        → 这个行业是否偏好/至少不排斥 40+
③ 硬门槛匹配度（原有）      → 学历/年龄/证书/行业经历 是否卡死
④ 专业背景门槛（原有）      → 是否要求特定理工科出身
⑤ 岗位自动化风险（原有）    → 该岗位会不会被系统/AI替代
```

**排序原则**：先用 ①② 做**淘汰**（砍掉下沉行业），再用 ③④⑤ 在剩下的行业里**排先后**。
顺序反了就会出现"这条路人岗匹配度很高，但这行业正在消失"的荒谬推荐。

### 6.2 2026 行业结论速查（详细数据见 `references/china-industry-sectors-2026.md`）

| 行业 | 景气度 | 一句话判断 | 处理 |
|---|---|---|---|
| **新能源/储能** | ↑↑ 增量 | 需求在涨、经验直接对口、不卡专业不卡年龄 | **主攻** |
| **医疗器械** | ⚠️ 冰火两重天 | 出口猛增 vs 头部裁员过万、招投标规模↓13% | **长线挂**（行业对但门暂不开） |
| **半导体/芯片** | ↑ 增量 | 上海是核心城市，2026 是"项目建设大年" | 备选第三 |
| **生物制药** | ⚠️ 收缩 | 专业门槛=药学/生物/化学，且在关厂裁员 | 暂缓 |
| **汽车/传统工业设备** | ↓↓ 存量血战 | 国内已是夕阳产业 | **划掉**（原先错排为备选） |
| **自动驾驶** | — | 纯技术岗（算法/感知/域控），仓储经验无法迁移 | **直接排除** |

### 6.3 真实案例（43岁/近14年仓储/无医械经验）

```（旧版·已作废，保留作反面教材）──
主攻：医药医疗器械GMP仓储   ← 门槛(体系/追溯/合规/规模)全中强项
备选：汽车/工业设备/高端制造 ← ❌ 错：汽车已是夕阳产业，被用户纠正
观望：上海烟草储运公司
放弃：烟草外包操作岗
```

```（2026-09 修正版）──
主攻：新能源/储能仓储        ← 景气度↑ + 经验对口 + 不卡年龄专业
长期挂：医疗器械（外企/头部） ← 行业对，但当前编制冻结，等行业回暖再投
备选：半导体/芯片仓储
暂缓：生物制药
划掉：汽车、自动驾驶、烟草
```

**结论句式**（保留，很好用）：
- 匹配度维度："你在A方向是专业溢价，在B方向是降维内卷。"
- 景气度维度："这条路你进得去，但它自己在往下走——进去了也是跟船一起沉。"

### 6.4 跳板思维（用户要"稳定干到60"但目标行业只有短窗口时用）

当用户核心诉求是**稳定性**、而唯一对口行业是**高增长但有窗口期**的（如储能：
2026-2027 高增长无忧，2028 后增速大幅回落），不要直接否定该行业，用**跳板框架**：

```
先进入（3-5年，攒行业经验 + 拿到行业标签）
   ↓
再迁移到该行业里"稳"的那一端
（国企能源板块 / 外企能源事业部 / 头部企业职能岗）
```

这样既拿到"明天就能投"的实操价值，又不违背用户的长期稳定性目标。
**注意**：储能企业多为民营 + 扩张期，加班文化普遍——必须让用户先明确
是否接受这个代价，再把他放进去。不要替他默认接受。
