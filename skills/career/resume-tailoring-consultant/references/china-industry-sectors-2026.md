## 一、医疗器械（2026）—— 冰火两重天，不是单向"欣欣向荣"

⚠️ **最大的认知陷阱**：同时存在两条相反的真实数据流，只看一边会得出完全错误的结论。

### 火的一边（增量）
```
2026上半年器械出口延续高增长
  高端医疗设备增速 超 330%（康复/影像/家用医疗为细分亮点）
人才报告：三个高增长方向"月薪4万招不到人"（福睿思特猎头《2026医疗器械行业薪资报告》）
全球器械市场 2025 估值超 5,700 亿美元，仍在增长
```

### 冰的一边（收缩，硬数据）
```
2026年至今 十余家头部械企裁员合计 ≥ 12,049 人（并购后整合口径）
2026年内 超12家头部械企宣布裁员，涉及 > 3,000 人（常规调整口径）
2025年 39家体外诊断(IVD)上市企业合计减员 8,087 人；73%企业削减研发部门
某医药流通龙头半年报：员工较上年同期 减少近万人
2026上半年 全国医疗器械招投标市场规模 同比下降近13%
耗材集采覆盖率：2024年 48% → 2026年预计 61%
某光学医疗设备企业：全球裁最多1,000人；中国区占其亚太营收21%；
    营业利润率预期 12.5% → 8~10%
某生物技术企业：营收同比-35%，关闭欧亚多个生产基地，裁员1,860人(=25%)
某放疗设备商：全球裁员约15%
```

### 四重驱动因素（裁员成因）
```
① 并购整合后的人员出清（最快、比例最高、执行最果断）
② 业绩增长失速（"抗周期"叙事在2026上半年财报上松动）
③ 中国集采政策纵深推进（价格下行 → 传统分销/进销差价模式失效）
④ 战略方向重塑（砍硬件、保软件/算法）
```

### ★ 对候选人的关键机会点（原文引用，最有用的一句）
> "传统制造岗位、低附加值销售岗位被压缩，而**具备数字化能力、技术研发能力、
> 跨境整合能力的人才，在行业调整期反而可能获得更多发展空间**。"
> "行业正在从拼规模转向**拼效率**，从铺人力转向**靠技术**。"

**翻译成简历策略**：在一个人力被砍、效率被追捧的行业里，
"会自建系统/数字化工具的仓储管理者"是**被需要的那一类**，不是被砍的那一类。
→ 用户若有自研/自动化/AI工具经历，**必须提到简历显眼位置**，不能当附注。

### 招聘趋势的结构性偏移
- 被压缩：传统制造岗、低附加值销售岗、行政后勤岗
- 在上升：数字化、研发、智能化、注册/合规相关岗
（另注：2026 三甲医院"裁员"实为**行政后勤岗的结构性优化**，非裁医护）

## 二、新能源 / 储能（2026）—— 唯一"四条件全中"的方向

### 景气数据
```
储能高端人才招聘需求 较2025年增长 28%（尚贤达2026年1月报告）
2026上半年 新型储能招标量同比 +41.8%，中标量同比 +61%
2026 全球储能需求大增 79%，美欧为核心引擎
液冷散热技术人才需求同比增速 > 1.5倍
远景能源 2026Q1 储能市占 13.7% 居第一
宁德时代 2026春招 6,000+ offer
欧洲户用储能装机量 2025年同比增长 180%
```
### ⚠️ 窗口期风险（必须告知用户）
> 行业判断原话：**"2026-2027年储能高增长无忧；2028年后增速大幅回落"**

→ **它不是"干到60"的行业。** 用户若核心诉求是长期稳定，须用"跳板思维"
（见 medical-device-and-soe-domain.md §6.4），不能直接承诺稳定。

### 其他风险
- 企业多为**民营 + 扩张期**，加班文化普遍（与德资节奏差异大）
- 利润分化严重（"是顶级赛道，也是最难赚的钱"）
- 锂价上涨推高成本、融资收紧可能导致项目延期/取消
- 大厂信号：宁德时代 2026春招提到 *"新能源汽车增速阶段性放缓，
  但储能正在快速增长，储能已成为新的增长曲线"* —— 需求在**转移**而非消失

### 为什么对仓储管理者对口度极高
```
锂电池/电芯/模组 → 重货 + 危化品存储 + 批次追溯 + 先进先出
                  + 温湿度敏感（锂电池对存储环境有要求）
→ "重货/危化品/批次追溯/温湿度" 与工业设备仓储经验几乎平移
→ 不卡专业背景、不卡40+年龄
```

## 三、半导体 / 芯片（2026）—— 上海是核心城市，备选第三

```
2026 是"十五五"开局之年 + 半导体项目建设大年（上海临港集成电路项目集中落地）
全球半导体进入扩产白热化；国产替代率约 35%
六类岗位大爆发；芯片人才争夺战持续
2026年薪资冠军：微电子科学与工程（校招 7,814元/月，应届口径）
上海：中芯国际、华虹、紫光展锐、上海微电子 + 张江设计公司集群
```
### 对仓储岗的相关性（值得注意）
某半导体巨头落子上海时明确提到：
> "仓库主体严格执行 **FM 高标准仓储规范**，核心库区同步满足 **FM 与 GB 双重消防标准**，
> 更好满足半导体**高价值产品对安全存储环境的严苛要求**"

→ 半导体仓储 = 高价值货品 + 高端仓储规范（FM标准）+ 防静电/洁净要求
→ **可作为"高端仓储管理能力"的迁移目标**
⚠️ 但 2026下半年芯片行业"告别盲目扩张、高薪挖人"，招聘逻辑在变，
   且该行业对本科学历+管理岗的年龄容忍度**未经验证**，不要过度承诺。

## 四、已排除的方向（附原因，避免下次重复推荐）

| 方向 | 结论 | 原因 |
|---|---|---|
| **汽车 / 传统工业设备** | ❌ 划掉 | **用户明确纠正：国内汽车已是夕阳产业**（存量血战，非增量）。⚠️ 早期版本曾错排为"备选第一"，理由是"同行迁移最顺"——**匹配度高 ≠ 值得去** |
| **自动驾驶** | ❌ 排除 | 纯技术岗（算法/感知/域控），与仓储管理经验无法迁移；行业本身在洗牌 |
| **生物制药（药厂GMP）** | ⚠️ 暂缓 | 专业门槛为药学/生物/化学，"自动化/机械电子"不在名单；且2026在关厂裁员 |
| **医药商业国企（上药/国药）** | ⚠️ 达不到目标 | 薪资 12-18K；且属"商业化国企"，会裁员。**能满足"干到60"的国企进不去，能进去的未必保得住** |
| **上海烟草** | ❌ 划掉 | 详见 medical-device-and-soe-domain.md §四 |

**"商业化国企 ≠ 铁饭碗"的实证**（知乎上药子公司员工原话，中可信度）：
> "上海的国企，裁员起来也是非常冷血的……上海医药子公司这种完全商业化的地方"

## 五、检索方法备忘（2026-09 实测）

### 搜索引擎级联限流的应对顺序
本次实测：DuckDuckGo(web_search) **超时** → 知乎搜索 **转登录墙**
→ 微博搜索 **返回0条** → 最终靠**搜狗**拿到可用结果。

```
有效顺序：
  1. cn-platform-full-stack 的 sogou 引擎（本次唯一稳定可用的入口）
     python3 ~/.hermes/skills/web-development/cn-platform-full-stack/scripts/cn_search.py sogou "关键词"
  2. 搜狗结果里微信公众号文章 → 直接抓 mp.weixin.qq.com 原文
     正则清洗：去 <script>/<style> → 标签换行 → 过滤长度<14的行
  3. 知乎/微博作为补充，遇限流立即切换，不要重试纠缠
```

### ⚠️ 微信公众号 URL 签名会过期
搜狗给的 `mp.weixin.qq.com/s?src=11&timestamp=...&signature=...` 链接
**签名有时效**。同一会话内先后抓两次，第二次即返回空内容（0行）。

→ **教训：拿到微信链接要立刻抓正文并落盘保存，不要留到下一步再抓。**
→ 若已过期：重新跑一次搜狗搜索拿新链接，或换关键词找同题转载。

### 引擎名坑
`cn_search.py` 支持 `sogou`、`baidu` 等；传 `360` 会报 `unknown mode 360`。
用前先确认引擎名（见该技能的 SKILL.md）。
