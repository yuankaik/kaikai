# 央企/国企求职渠道结构 + SPD 岗位识别（2026-09 实测）

配合 `references/medical-device-and-soe-domain.md`（行业定性与方向排序）使用。
本文件解决**"投哪、怎么投、哪个岗位是陷阱"**——是渠道层，不是行业层。

---

## 一、最大陷阱：SPD 岗不是仓储岗，别被"运营经理"头衔骗了

### 现象

搜"医疗器械 仓库经理 上海"时，**上药医疗器械（上海）有限公司**反复出现在结果里，
岗位名是 `SPD运营经理` / `医院供应链现场管理员`。头衔带"经理"、带"供应链"，
看起来是候选人该投的岗。**投了就是降级。**

### SPD 实际做什么（知乎从业者原话，交叉两处来源确认）

> "对接医院SPD业务，整理填写公司及供应药械的属性信息；填写订单相关药械配送信息；
> 收集订单相关票据：配货单、发票、校验单；盘库、退换货、价格变更、**注册证变更**
> 等日常零散工作。"

另一条更直接：

> "就是第三方驻院服务人员。没啥前途。。。"
> （南京鼓楼医院 SPD 项目运营人员岗位评价）

### 为什么这是降级

| 维度 | SPD 运营 | 仓储管理岗 |
|---|---|---|
| 办公地点 | **医院内**（驻院） | 仓库/物流中心 |
| 核心工作 | 票据、注册证、价格维护等**行政流** | 实物仓储**控制流** |
| 能力要求 | 细致、耐心、流程性 | 库容规划、团队、KPI、布局 |
| 晋升路径 | 窄，易被替代 | 仓储经理→物流经理→供应链总监 |

**判定规则**：一个岗位如果它的 JD 里出现"注册证变更""票据收集""填报属性信息"，
而**没有**"库容规划""储位""拣货效率""盘点""团队管理"——它就不是仓储岗，
不管头衔叫什么。**这是"文员+协调员"岗，是能力降级，不是职业升级。**

### 但要顺手记一条正面情报

出现 SPD 招聘意味着**该公司的医疗器械流通业务在本地有编制**。
真正的机会不在 SPD 岗本身，而在**同一家公司/同一集团下的仓储物流本体**。
所以：看到 SPD → 不投 SPD，但**立刻去查同集团的物流中心主体**（见第三节）。

## 二、"名气大"不等于"入口开"——清单要按入口排序，不按名气排序

给用户排目标企业时，**默认的排序冲动是按知名度排**（美敦力、强生、西门子放最前）。
这是错的。正确维度是**"入口真实存在且匹配"**：

```
按入口排序（推荐）              按名气排序（错误）
① 有独立仓储招聘主体的物流公司   ① 全球500强
② 本地国企/央企（编制持续发布）  ② 行业头部
③ 有公开社招页面的外企           ③ 品牌响亮
④ 头部生产厂（门槛高、卡行业经验） ④ ...
```

**理由**：生产厂的 GMP 仓储岗 JD 普遍硬写"3年以上医疗器械/药品仓储经验"。
没有行业经验的候选人**过不了评估阶段**（初筛能过是因为合规词命中）。
把这类放第一顺位，等于让用户把精力花在最可能被拒的地方。

## 三、上药系 / 国药系：招聘主体的正确识别方式

### 关键区分：集团 ≠ 招聘主体

搜"上药控股 招聘"会返回一堆集团层面的、不相关的页面。
**要找的是"专门做物流仓储的子公司主体"**。

| 主体 | 性质 | 为什么它是好入口 |
|---|---|---|
| **上海医药物流中心有限公司** | 上药集团旗下**专业物流主体** | ✅ **招的就是仓储岗**，规模大，GSP合规。仓储候选人的第一顺位 |
| 上药控股有限公司 | 集团总部 | 招聘页多为管理/商务岗，仓储岗少 |
| **上药医疗器械（上海）有限公司** | 医械流通，**规模中等** | ⚠️ 可投，但注意：① 主要招 SPD（陷阱，见第一节）② 办公在杨浦但**仓库可能在嘉定/青浦/松江**，通勤要先确认 |
| 国药控股上海 | 央企流通 | ✅ 仓储网络最大，央企刚需。缺点：流程慢、可能被安排到一线 |
| 华润医药商业上海 | 央企商流 | 可投，但上海非其最强区域 |

### ⚠️ 投流通企业前必须问清的一件事：**仓库在哪**

这是 43 岁以上候选人的**实际可行性问题**，重要性高于薪资。
区域型流通商常"办公在市区、仓库在外环外"。单程通勤 1.5 小时以上，
对一个打算干到 60 岁的人是不可持续的。**投递前先确认仓库地址，不要等到面试才问。**

### 国企/央企的公示渠道（绕开平台算法）

本次实测发现：**上药医疗器械（上海）的招聘信息发布在「上海市杨浦区人民政府官网」**。
这不是偶然——国企/央企有**属地公示**义务，招聘信息会挂在区政府/人社局官网。

可用渠道：

```
① 目标企业集团官网「人才招聘」/「社会招聘」
② 企业所在区的人社局 / 区政府官网「重点企业招聘」板块
   （例：杨浦区、嘉定区、松江区人社局）
③ 企业官方微信公众号招聘号（注意：微信文章 URL 签名会过期，见下）
④ 猎聘 / 前程无忧（国企现已普遍在这两个平台发布）
```

**微信公众号 URL 坑**：`mp.weixin.qq.com/s?src=11&timestamp=...&signature=...`
这类链接**签名会过期**，抓到的内容几天后失效。要留证据就立刻转存正文，
不要只存链接。

## 四、平台分层：猎聘 vs 51JOB vs BOSS直聘

### 定位差异（决定"要不要写期望薪资"）

| 平台 | 用户画像 | 期望薪资写不写 | 理由 |
|---|---|---|---|
| **猎聘** | 35+ 管理岗 / 被猎头主动搜 | ✅ **写** | 用户是"被搜"的一方。写明期望能过滤掉够不着的低价岗，避免被捞去谈一个不可能的 offer |
| **前程无忧 51JOB** | 外企/国企主力，海投 | ✅ **写**（区间） | 见下方"修正"▲ |
| **BOSS直聘** | 量大但小公司多，应届生战场 | ❌ 不写 | 43岁+管理岗投这里会被算法排到很后面，**不要作为主战场** |

### ▲ 修正（2026-09-23，跨行业定价模型取代"51JOB留空"）

**早期建议是"51JOB 留空期望薪资"（怕被机器按超预算筛掉）。这对单一目标行业成立，
但对"跨多条赛道投递"的候选人是错的**——留空会导致不同价值的岗位被混在一起谈，
失去按行业定价的能力。

**正确模型：统一填区间 + 面试按行业分档谈。**

```
填表时：统一填 15-22K（平台通常只允许一个区间）

面试谈时按行业分档：

第一档（可降薪）：医疗器械 / 医药流通
    → 15K-20K 可接受，通勤越近越好
    → 理由：这 3 年买的是"行业入场券"（GSP/GMP 资历，见
           `career-path-and-early-experience.md` §5），薪资让位

第二档（守底线）：非医药的工业外企 / 央企国企
    → 17K-22K，低于 17K 不谈
    → 理由：这些不给医药行业资历，薪资必须到位

底线：任何行业低于 15K → 不谈
```

**背后的决策逻辑（必须问用户才能定出这两档）：**

```
用户的优先级排序 = 行业 > 薪资 > 距离
所以薪资松紧要跟着"行业价值"变：
· 医械/医流通 → 行业价值高 → 薪资可以让
· 其他行业    → 行业价值为零 → 薪资必须守

⚠️ 反向自查：如果一家非医药公司给 15K 但离家近，
   那是"用职业生涯第一优先级换了通勤时间"——不值。要主动点破。
```

**这两档数字必须从用户嘴里问出来，不能替他定。** 问法见
`career-path-and-early-experience.md` 第六节的"三选项对照题"。

### 一条反常识建议

**先做猎聘，不要先投 BOSS。**
"14年德资仓储管理经验 + 12000 SKU + 多仓团队"在猎聘上是**猎头会主动捞的画像**；
在 BOSS 上则和应届生一起排队。顺序错了会白白消耗简历曝光。

### "分开头"的正确理解（重要，易误解）

用户说"猎聘和 51JOB 分开头"时，**大概率指平台操作层的差异，不是简历抬头要写两个版本**。
**不要因此去维护两份不同抬头的简历**——理由见 SKILL.md §4.5（抬头解锁后不做多版本）。

正确做法：
```
简历文件：一份（抬头只写岗位，不写行业）
渠道差异：放在平台操作层
  猎聘 → 填期望薪资
  51JOB → 不填期望薪资
```
先跟用户确认"分开头"指哪一层，不要默认成"要做两份简历"。
**一份文件要维护，降低投错文件的概率**（投递时翻文件夹是真实的失误来源）。

## 五、国企版简历的三个"必问项"（缺一不可，动笔前先问）

国企/央企的简历筛选逻辑与外企/民企**完全不同**。它们看的是：

| 必问项 | 为什么必须问 | 怎么用 |
|---|---|---|
| **政治面貌** | "中共党员"是**实打实的加分项**，部分仓储主管岗直接写"党员优先" | 是党员就写上去。**没有绝不编造**——国企政审会核实 |
| **职称** | 国企体系内职称权重很高（助理工程师/物流师等） | 有就单列一行；没有就写"备考中"（如果确实在考） |
| **户籍** | 部分国企岗位有户籍倾向，上海户籍是优势 | 是上海户籍可写 |

**问法**：一轮只问这 3 个（遵守 SKILL.md §1 的"一轮 2-3 问"规则）。
明确告诉用户"没有的就说没有，我只写真实的"。

### 国企版 vs 外企版的内容取舍差异

| 维度 | 国企/央企版 | 外企/民企版 |
|---|---|---|
| 稳定性 | **强化**（德资14年 = 稳） | 正常表述即可 |
| AI/自研数字化 | **弱化** | **强化**（提显眼位置） |
| 体系/合规 | **强化**（ISO三体系、GSP） | 强化 |
| 格式 | 偏纸质版、官方渠道投递 | 电子版、平台投递 |

**⚠️ 为什么国企版要弱化"自己搞AI"**：国企领导对"业务人员自主开发系统"可能无感，
甚至警惕（越过 IT 部门=不合规、不可控）。外企视为创新，国企可能视为不守流程。
**同一个亮点，两种体制下价值相反——不要一份简历投到底。**

## 六、官网≠岗位源：实地核查的三种结果（2026-09-23 实测）

**方法论教训（比结论更重要）**：给用户排渠道时，**不要凭\"官网一定有招聘页\"的常识推断**，
要真的访问一次。本次实测三个目标，结果三种都不一样，且全部推翻了纸面推断。

### 结果A：招聘门户真实可用，但该岗位为零（上海医药）

```
入口：https://sph.zhiye.com/social/jobs   （上海医药官方招聘门户，北森 zhiye.com 系统）
实测：全部职位 共 85 个；搜索\"仓储\" → 命中 2 个，均为**误命中**
     （临床项目经理、QA工程师——是岗位描述里提到\"仓储\"，不是仓储岗）
仓储/物流类岗位实际数量：0
```

**\"零\"本身是硬情报**，价值高于\"官网有招聘页\"这句废话：

- 上药集团门户只放**研发/生产/质量/医学**岗（中央研究院、上药第一生化）
- 仓储岗**不走集团门户**，走子公司自主招聘（上海医药物流中心 → 51JOB/猎聘）
- 结论：**不要教用户去刷 sph.zhiye.com 等仓储岗**，刷了也是空的。
  让它当\"趋势观察窗\"（每月一次），不是主战场

**操作细节**：官网导航里的\"社会招聘\"是 JS 点击（click 后不跳转是正常的）。
正确拿法是读 `a.href`：
```javascript
Array.from(document.querySelectorAll('a')).filter(a=>/招聘|人才/.test(a.textContent))
  .map(a=>a.textContent.trim()+' => '+a.href).join('\n')
```
北森系统页面有 cookies 弹窗遮挡，先点掉\"我知道了\"再读职列表。

### 结果B：官网招聘板块是空壳（国药控股）

```
入口：https://www.sinopharmholding.com/  → 人才发展 → 人才招聘
实测：子页面 HTTP 000 / ERR_EMPTY_RESPONSE；点\"人才招聘\"实际跳转到**党建栏目**
```

**央企招聘走集团统一平台，子公司官网只做宣传、不放岗位。**
遇到这类站，**不要死磕**（换路径超过 3 次就停），直接转商业平台。

### 结果C：真实岗位在商业平台，不在官网（结论）

本次挖到的**实际在招岗位**（非推测）：

| 公司 | 岗位 | 来源渠道 |
|---|---|---|
| 上药医疗器械（上海） | SPD运营经理、医院供应链现场管理员 | 杨浦区政府官网、微信招聘号 |
| 上海医药物流中心有限公司 | 多岗位（独立招聘页） | 前程无忧51job、猎聘 |
| 联影医疗 | 仓库主管 | 招聘平台 |
| 美敦力（上海）管理有限公司 | 多岗位 | 前程无忧、BOSS直聘 |
| 上海瑛泰医疗 | 仓库配货员（嘉定） | 招聘平台 |

### 通用规则（写进交付物）

```
【每日必刷】商业平台，岗位真实流动
  ① 猎聘        ② 前程无忧 51JOB
     搜索词：仓库经理 / 仓储经理 / 物流经理 / 仓库主管
     行业筛选：医疗器械、医药、医药流通
【每周必刷】官方渠道，频率必须低于平台
  ③ 目标集团招聘门户（当趋势观察窗）
  ④ 各区人社局/政府官网（国企属地公示）
【每月一次】BOSS直聘、猎头直连
```

**官网刷新频率必须低于商业平台。** 官网岗位更新慢（上药门户最新岗是 9月10日 的），
平台是每日流动的。把主要精力放猎聘+51JOB，官网当补充。

### 猎聘注册的一个真实操作要点

**必须把\"在线简历\"字段填完整，不能只传 PDF 附件。**
猎头在猎聘上搜人是**搜在线简历的结构化字段**（职位、公司、年限、技能标签）。
只挂 PDF 的话内容不进数据库，**猎头搜不到这个人**——等于白注册。

要填的核心字段：
```
当前职位 / 当前公司 / 工作年限 / 管理规模（人数+仓数+SKU）
技能标签：SAP WM/MM、库存管理、仓储管理、团队管理、GMP、批次追溯、ISO体系
期望职位：仓储物流经理 / 仓库经理
期望行业：医疗器械、医药、医药流通
```
