# Elementary Routine Design

Design structured daily routines for elementary school children that actually last beyond 3 days. The hardest problem is not creating the schedule — it's making it survive Week 1.

## Trigger Conditions

- User asks to design/optimize a child's daily routine, summer schedule, or check-in chart
- User shares an existing schedule and asks if it's sustainable
- User asks to create a printable daily/weekly task card
- User asks "can a 10-year-old stick to this?"

## Core Design Principles

### 1. Task Block Limits

| Age | Max mandatory blocks | Max per-block duration | Total daily learning |
|-----|---------------------|----------------------|---------------------|
| 8-9 | 3 | 40-45 min | 2-2.5 hours |
| 10-11 | 4 | 50-60 min | 3-3.5 hours |
| 12 | 5 | 60 min | 3.5-4 hours |

**One block = one discipline.** Don't mix Chinese and Math in the same block — cognitive switching cost is 2-3x higher for children than adults. Keep blocks single-discipline.

**Count cognitive switches, not tasks.** A block with 3 sub-tasks inside one discipline (e.g., reading → handwriting → sentence collection) is one switch. A schedule that bounces between subjects is multiple switches even if it has fewer "items."

### 2. The 4-Block Sweet Spot (for Grade 4-5)

After extensive analysis of Chinese parenting community success patterns, the optimal structure for a 10-year-old:

```
Morning (self-directed, high-focus):
  Block 1: Morning routine + quick math drill (warm-up)
  Block 2: Chinese — three sub-blocks (基础积累 + 阅读 + 背诵, total 60 min)
  Block 2a: 基础积累 (15 min) — rotating skill types: 看拼音写词语/字音字形/成语/修改语段/句式仿写/说明方法
  Block 2b: 阅读 (30 min) — rotating text types: 记叙文/说明文/非连续性文本
  Block 2c: 背诵 (15 min) — alternating: 古诗 (odd days) / 成语 (even days)
  Block 3: Math/AI learning (device-based, before lunch)

Afternoon (lower willpower, alone):
  Block 4: English (vocab + reading + rotation)
  → Reward unlocked AFTER completion

Evening (parent present):
  Passive input (listening) + retrieval practice (parent-led review)
  Exercise → shower → memory window → parent check-in
```

### 3. The "Don't Count Exercise" Rule

Athletic children experience exercise as reward, not task. Making them check a box for "exercise" turns joy into obligation. Label it as a natural part of the evening flow, never as a task block to check off.

### 4. Reward Design: Next-Day Deferred

**The #1 pitfall from Xiaohongshu/zhihu parenting communities: same-day electronic rewards destroy sustainability.**

When a child knows "finish English → Switch now," the entire afternoon English block becomes a race to the finish, not learning. The child rushes, quality collapses, and resentment builds.

**Rule: Today's checkmarks → tomorrow's reward.**

```
Today: Complete ≥3 of 4 blocks → Tomorrow: 45 min Switch
Today: Complete 4 of 4 blocks → Tomorrow: 90 min Switch

Never same-day. Never "do this and get that now."
```

This also makes the evening parent check-in meaningful: the child knows tonight's signature controls tomorrow's freedom.

**Switch time windowing:** Lock Switch to a fixed window (e.g., 15:30-17:00) using parental controls. Outside this window, the device is inaccessible. This prevents morning gaming and teaches time-boundary awareness.

### 5. Weekly Cycling: 5+1+1

60 consecutive days of identical schedule → Week 3 collapse.

```
Mon-Fri: Full routine (4 blocks, ~3-3.5h learning)
Saturday: "Light touch" — 1-1.5h, different format, no checkboxes
  - Reading: just "read another chapter" of a fun book, no exercises
  - Math: "game mode / challenge mode" only, no new lessons
  - No output required, no grading, no parent signature
Sunday: Complete rest (optional: 5 min flip through error book)
```

The light touch prevents Monday restart friction without feeling like work. The complete rest prevents cumulative mental fatigue.

### 6. Evening Architecture: Exercise → BDNF Window → Retrieval

```
Dinner → 30 min digestive rest (peak drowsiness, do nothing)
       → Passive input OK at 30-60 min post-meal (listening, not solving)
       → Exercise (60 min)
       → Shower (15 min)
       → BDNF MEMORY WINDOW (20 min): retrieval practice
       → Free time → Sleep
```

**BDNF (Brain-Derived Neurotrophic Factor) surges after exercise, creating a 30-60 minute window of heightened hippocampal activity.** This is ideal for retrieval practice (extracting already-learned information), NOT for learning new content.

What to do in the BDNF window:
- Quick mental math spot-checks (2 min)
- Recite today's good sentence (2 min)
- Flash 4 random English words, parent says Chinese, child says English (3 min)
- "What happened in My Weird School today?" (2 min)
- Feynman check: "Teach me what AI Math taught you today" (3 min)
- Flip through error book, confirm yesterday's gaps (2 min)
- Sign off + positive comment (1 min)

**Tone is everything:** "What was fun today?" not "Recite what you learned." Curiosity opens mouths; interrogation closes them.

### 7. Post-Meal Cognitive Suitability

| Time after meal | Brain state | Suitable tasks |
|-----------------|-------------|----------------|
| 0-30 min | Digestion peak, drowsy | ❌ Nothing cognitive |
| 30-60 min | Gradually recovering | ✅ Passive input (listening, light reading) |
| 60+ min | Normal | ✅ Active thinking |

Listening to English audio and parent-led error review are passive enough for the 30-60 min window. Math problem-solving is not.

### 8. Failure Tolerance: The "3-out-of-4" Safety Net

Demanding 100% completion every day guarantees collapse. Design the reward threshold at 75%:

```
Threshold: 3 of 4 blocks completed → tomorrow's base reward unlocked
Full completion (4/4) → bonus reward

If one block fails: don't make it up that evening.
Just note it, move on, try again tomorrow.
The 3/4 safety net prevents "one failure → full day abandoned."
```

Never punish a missed block the same day. Never make the child "make up" work during free time. The consequence is natural: fewer stars → less Switch time tomorrow.

### 9. Sleep Anchor: Decouple Child Wake-Up from Parent Commute

The highest-leverage lever in a school-term routine is the child's wake-up time. Parents often wake 1.5-2h before the child needs to (long commute), and the child gets dragged along, chronically sleep-deprived.

- A 10-year-old needs 9-11h. Count BACKWARD from wake-up to set lights-out, never forward from "when homework ends."
- If the child can wake later than the parent (grandparent/sitter handles drop-off), sleep hits target automatically — 21:10 lights-out + 7:00 wake = 9.7h.
- ALWAYS ask who does drop-off and what time the child actually wakes BEFORE designing the evening schedule. Guessing "child wakes with parent" produces a schedule that under-sleeps the child by 1.5-2h. This one question outranks every other learning decision.

### 10. In-School Study Hall Changes Homework Positioning

When the child has an in-school homework/study block (晚自习/自习课, e.g. 15:45-17:30), home "homework help" is NOT re-doing the work — it is a targeted patch session.

- In-school block length sizes home help: 105 min in school → ~20 min at home (spot-fix only the 1-2 points that actually blocked them), NOT 40 min of re-teaching.
- Low quality is caused by "nobody supervises + nobody answers when stuck", NOT by insufficient volume. Adding more minutes at home makes it worse.
- The fix for low in-school quality is the weekly spot-check threat (he knows he'll be quizzed → won't coast), not more evening minutes.
- Ask for the in-school schedule (block time + who supervises) as a REQUIRED input before sizing the evening homework slot. Getting this wrong is the #1 cause of over-loading the evening.

### Time-Ledger Diagnosis (3 steps for any evening re-plan)

1. Write the current schedule as a time ledger; mark every slot that violates physiology (homework after exercise+shower = lowest brain state; empty 30 min right after dinner = wasted gold window).
2. Re-sort by the three physiology rules: homework → 60 min after dinner (brain recovered); recitation → within 30-60 min after exercise (BDNF memory window); lights-out → fixed backward from wake-up.
3. Reconfirm the two unknowns that change the answer: child's actual wake-up time / drop-off person, and in-school study-hall length. Both materially change the final numbers.

After re-planning, generate a printable schedule card via python-docx (see `scripts/gen-schedule-card.py`) — Word to the desktop, editable and printable.

### Common Schedule Adjustments

When iterating with a parent, common friction points:

| Parent concern | Response |
|---------------|----------|
| "Is 3 hours enough for catching up?" | 140+ hours over 8 weeks. Consistency beats daily volume. 3h × 8 weeks with no collapse > 5h × 3 weeks then abandoned. |
| "Weekend rest will make them fall behind" | 5+1+1 with light Saturday touch = ~17.5h/week. The Saturday light touch prevents Monday friction. Sunday rest prevents Week 3 burnout. |

## 艾宾浩斯单词曝光系统 (Ebbinghaus Vocabulary Exposure)

### Core Logic
- 20 words per batch, Mon-Fri (Day01-05, Day06-10...)
- Review intervals from learning date: **+1, +3, +6, +14, +29 days**
- Same day may accumulate: new 20 + review 120 = 140 words
- **Exposure mode only**: show the word list, no testing. Quick glance to deepen impression.

### File Structure
```
~/错题/
  艾宾浩斯_Day01.txt    # One word per line: word 中文
  艾宾浩斯_meta.txt     # Tracks learning dates: Day01 2026-06-30
```

### Cron Push
- Use no_agent mode running `ebbinghaus_review.py`
- Script reads meta.txt, calculates which Day batches are due, outputs all words
- If no review due, script outputs empty → silent (no notification sent)

### Key Pitfalls
- **Intervals are per-batch, not uniform**: Day05 and Day01 each have their own review calendar starting from their respective learning dates.
- **Exposure ≠ quiz**: Push is pure display list. Never ask "please answer the meaning of..."
- **Word count scales fast**: After 5 batches, daily review load stabilizes at ~100 words (5 intervals × 20 new). This takes ~5 minutes oral review.

## 66-Day Habit Formation Tracking

When the parent asks "what habits should we build and for how long," generate a printable tracking table.

### ⚠️ FIRST: Never Propose More Than 2 New Habits

Kai哥's iron rule (verified across multiple sessions): **动作越少越能坚持。** Never design more than 2 new habits at once for a 10-year-old catching up. The child WILL drop habits beyond 2. The parent WILL confirm this. Starting with 2 and adding a 3rd after 66 days is always better than starting with 4 and watching all of them fail.

If you ever find yourself listing more than 2 habits in a proposal, STOP and cut. This is a non-negotiable constraint, not a suggestion.

### The 66-Day Rule

London University College research (widely cited on Xiaohongshu/zhihu): 21 days is just the starting point; true habit automation takes ~66 days on average. For children, plan a full 66-day window.

### Parasitic Habit Design

New habits MUST attach to existing routines — never create standalone "habit time":

| New habit | Parasitic on |
|-----------|-------------|
| 晨读 10min | 起床→刷牙→洗脸 链 |
| 口算 5min | 晚间运动后→背诵前 |
| 晚间背诵 20min | 已有亲子时间 |

Never: "4:00pm is habit time." Children don't track clocks; they track flows.

### Start With 2, Not 4

User preference (kai哥, verified across multiple sessions): **动作越少越能坚持。** Never propose more than 2 new habits at once for a D-level student catching up. The skill defaults to 4 in the table below, but START WITH ONLY 2 and don't add more until 66 days pass.

For a 10-year-old catching up, the core menu (pick 2, max):

1. **晨读** (10min, self-directed) — read aloud: poetry/English/textbook rotation
2. **口算** (5min, parent-led) — oral math, 20 questions, no writing
3. **晚间背诵** (20min, parent-accompanied) — vocab 10min + classical Chinese 10min
4. **练字** (15min, self-directed) — one page/day

**Default recommendation: 晨读 + 晚间背诵.** These are the two highest-leverage habits for 四升五. 口算 can be folded into existing math practice. 练字 can be added after 66 days if still needed.

Reading is excluded — if it's already a spontaneous habit, tracking it turns joy into obligation.

### Father-Son Joint Tracking

When the parent is also building habits, create ONE combined tracking table. 

**Default: 2+2 format (2 for parent, 2 for child).** Never more.

```
日期 | 天数 | 爸① | 爸② | 乐① | 乐② | 备注
```

Example pairings (child habit → parent habit):
| 乐 | 爸 | Why |
|:--:|:--:|------|
| 晨读 10min | 不刷手机 30min | 乐在读书，爸没法刷 |
| 晚间背诵 20min | 睡前写3件事 | 陪背完顺手写明天的计划 |

### Table Format

Generate a 66-day DOCX with:

```
Date | Day# | ☐晨读 | ☐口算 | ☐背诵 | ☐练字 | Weekend | Notes
```

Key design rules:
- **Weekends: only 晨读 + 晚间背诵** (口算 and 练字 rest)
- **Blank = OK.** Never punish a missed checkbox. Tomorrow continues.
- **Phase markers** at days 1, 7, 21, 42, 66 for motivation
- **Weekly summary rows** for parent reflection: hardest, easiest, one-sentence note
- **Reward: 7 consecutive full-attendance days → small reward** (child chooses)
- Font: 宋体 8pt, compact layout for one glance
- Output: `/mnt/c/Users/admin/Desktop/佳乐66天习惯养成追踪表.docx`

### Core Philosophy

> "The goal is not perfection. The goal is getting back on track after a miss."

One missed day = continue tomorrow. Two missed days = continue tomorrow. The checkbox is a signal, not a verdict.

### Don't Add More Until 66 Days Pass

Adding a 3rd new habit before the first 2 are automated leads to all three collapsing. The system is fragile during the first 30 days. Protect it.

## Pinyin vs English Phonics: Keep Them Separate

For Grade 4 students who still confuse pinyin and English alphabet sounds:
- **Do NOT** teach them side-by-side in the same program. The contrast method backfires at this age.
- **Do** a pure pinyin reinforcement program first (7 days, no English letters at all)
- Only after pinyin is solid, introduce English phonics separately
- Delete any reference materials that mix the two systems — they'll end up on the desk and cause confusion

## DOCX Merging: Tables Are Not Paragraphs

When merging multiple DOCX files into one with python-docx, do NOT iterate `src.paragraphs` alone — tables are separate objects and will be silently dropped. The correct approach iterates `src.element.body` children, which interleaves paragraphs (`w:p`) and tables (`w:tbl`) in document order:

```python
def append_docx(dst, path, skip_answers=False):
    src = Document(path)
    plist = list(src.paragraphs)
    tlist = list(src.tables)
    pi = ti = 0
    for child in src.element.body:
        if child.tag == qn('w:p') and pi < len(plist):
            sp = plist[pi]; pi += 1
            txt = sp.text.strip()
            # Filter answer-hint paragraphs from student version
            if skip_answers and any(k in txt for k in [
                '如果第', '题错了', '答案速查', '家长',
                '短文想告诉我们', '用铅笔', '参考', '解题'
            ]): continue
            # copy paragraph runs...
        elif child.tag == qn('w:tbl') and ti < len(tlist):
            copy_table(dst, tlist[ti]); ti += 1
```

Table copying requires reconstructing rows, cells, and paragraph runs, preserving fonts and alignment. Style the destination table with `'Table Grid'` for visible borders.

## Student/Parent Content Separation

Reading comprehension source files (especially the 60-day curated set) embed answer guides and parent instructions inline. These MUST be filtered from the student merged version. The parent version receives unfiltered content.

### Answer Filter: Line-Level + Block-Level

Use a two-tier filter when appending reading content to student DOCX:

**Line-level filter (`is_answer_line`):**
Skip paragraphs starting with or matching any of:
- `标准答案`, `评分点`, `常见错因`, `错因标签`, `依据段`
- `家长批改提示`, `孩子重写任务`
- Bullet scoring points: lines starting with `•` or `·`
- `共X分` pattern
- Error tags: `#中心`, `#信息`, `#词语`, `#句子`, `#原因`
- `如果第X题错了`, `答案速查`, `用铅笔画出`, `参考答案`, `示例开头`

**Block-level filter (`skip_block`):**
When a paragraph starts with `家长批改提示` or `孩子重写任务`, set `skip_block = True`. Skip ALL subsequent paragraphs until:
- A separator line (`───`) is encountered, OR
- The next passage heading (`短文一/二` or `第X天`) appears
Then reset `skip_block = False`.

This prevents multi-paragraph parent-guide sections from leaking into the student version while keeping the actual questions and passages intact.

**口算 answer exclusion:**
Filter sections whose title contains `答案` (e.g., "答案速查表") when generating student 口算 files. Parse section headers from MD `## ` lines and drop matching sections before building tables.

### Verify: Zero Leaks

After merging, always verify by scanning the student file's reading section for answer markers. A single leaked `标准答案` or `评分点` line means the filter missed a format variant — update the keyword list and re-merge.

## PermissionError: Word Locked Files

When merging into `/mnt/c/` (Windows desktop), files may be locked by Word. The merge loop must catch `PermissionError`:

```python
try:
    doc.save(path); ok += 1
except PermissionError:
    skipped += 1
    print(f"⚠️ Day{day:02d} locked — close Word and re-run")
```

Pre-merge cleanup: delete existing merged files first (`os.remove`). If any fail with `PermissionError`, skip that day and continue — merge the rest, then retry the skipped days after the user closes Word. Never let one locked file block the entire batch.

## 口算 MD→DOCX Regeneration

口算 source files are stored as Markdown tables (question|answer columns). When regenerating, produce two versions:

**Student version — clean, no numbers, no answers, spacious:**
- **2-column layout only** (题目 | 题目). No 题号 column — the numbers waste space and add visual noise.
- Strip ALL numbering from questions. Show just `300+500 = ______`, not `1. 300+500 = ______`.
- Filter out any section whose title contains `答案` (e.g., "答案速查表") — answers must NEVER appear in the student version.
- Set row height to `atLeast 500` (≈0.9cm) via XML `w:trHeight` for comfortable writing space.
- Add `space_before=Pt(6)` and `space_after=Pt(6)` on cell paragraphs for extra breathing room.
- Font size Pt(11) for questions, left-aligned in cells.

**Parent version — compact 4-column with answers:**
- Layout: 题目 | 答案 | 题目 | 答案 (4 columns, two Q&A pairs per row).
- Include a header row: `['题目','答案','题目','答案']`.
- Font size Pt(9) for compact printing.
- Include ALL sections including 答案速查表.

**Key principle: 15 minutes ≠ 100 questions.** A D-level student can realistically do 35-45 questions in 15 minutes (simple: 3-5s, multi-digit: 8-15s, applied: 15-30s). When the MD source has 100 questions, trim to ~40. Never present 100 questions with "15分钟" on the label — the mismatch erodes trust in the whole plan.

**Proportional sampling across sub-modules:** Do NOT take the first N questions sequentially — that drops entire sub-modules. A typical 口算 file has 4 sections (热身→核心A→核心B→应用). Taking just the first 40 questions = only 热身 + half of 核心A. Instead, allocate proportionally:

```python
TARGET = 40
for each section:
    take = max(1, int(TARGET * section_questions / total_questions))
# Distribute remainder to larger sections
```

Result: 热身(~10) + 核心A(~10) + 核心B(~10) + 应用(~10) = all four modules covered. Single-topic files (找规律, 竖式, 方程) naturally have 1 module — the proportional formula still works, it just allocates all 40 to that one module.

Strip `(25题)` suffixes from section headers since the actual count is now different. The original count in the header becomes misleading after proportional trimming.

Parse the MD by detecting `## ` section headers and `|...|` table rows. Skip header rows containing `题目`. Map days to source files via a lookup dict — some files use branded names (学而思) that may not exist as .md; fall back to same-grade alternatives.

Always add a header block with student name/date/time/score blanks for a professional worksheet feel.

## Reading Drives Learning: Don't Let Recitation Kill It

When a child discovers intrinsic reading motivation (actively asking for books, voluntarily reading beyond assigned time), this is the single most valuable asset in their learning journey. Forced memorization tasks — timed vocabulary recitation, scheduled classical text背诵 — can actively undermine it.

### The Two Forces

| | 阅读 (Reading) | 定时背诵 (Timed Recitation) |
|---|---|---|
| Cognitive mode | Absorption (passive intake) | Output (active retrieval) |
| Driver | Intrinsic interest | External compulsion |
| Cognitive load | Low (follow the story) | High (deliberate memorization + recall) |
| Emotional experience | Pleasure | Pressure |

When both run simultaneously, they pull in opposite directions: reading pulls forward, recitation pulls backward. The energy spent resisting recitation is energy not spent reading.

### Strategy: Parasitic Learning

Instead of running a separate memorization track, make learning parasitic on reading:

**Vocabulary: from "memorize" to "encounter"**
- Cancel standalone vocabulary memorization sessions
- While reading, circle ≤2 unfamiliar words with a pencil
- Next day: naturally revisit them when flipping back through the book
- No separate "vocabulary time" — it dissolves into the act of turning pages

**Classical Chinese (文言文): from "recite" to "listen"**
- Pause all recitation requirements
- Switch to one白话文言 story per day (e.g., 世说新语 in modern Chinese)
- Goal: comprehension only, no recitation, no original text required
- Build affinity first: "文言 = interesting old stories," not "文言 = burden to memorize"

**Evening check-in: from "test" to "share"**
- Old: "Come recite your words."
- New: "What did you read today? Any interesting words?"
- Shift from task-inspection to experience-sharing

**Evening parent-child recitation: role reversal**
When solo memorization fails but parent-accompanied recitation is attempted:
- Do NOT play the examiner. Play the fellow student.
- You recite to him, deliberately making mistakes, and let him correct you.
- Children get a dopamine hit from catching adults' errors — they'll pay closer attention than under interrogation.
- Set a floor rule: on tired days, just read aloud together (no memorization requirement). Never skip entirely, but lower the bar to maintain the habit.
- Limit: 3 new words/day + review. Exceeding 3 triggers resistance. Extra review counts as bonus, not quota.

**Golden rule**: A child who asks for books unprompted is in a rare, precious state. Do not sacrifice it on the altar of memorization quotas. Reading volume naturally builds vocabulary — trust the process.

### Saturday-Sunday Rest: It's a Feature, Not a Gap

When a child accepts Mon-Fri daily practice but has 2-day weekend rest:
- **This is the correct design.** Weekend blank space prevents cumulative fatigue collapse.
- Do NOT fill the weekend with "light tasks" unless the child initiates.
- The Monday restart friction is real but manageable — much smaller than Week 3 burnout.
- A child who voluntarily refuses phone/games during rest days (choosing to read instead) signals that the system is working. Don't break it by adding requirements.

### Vocab-Reading Alignment: Verify, Don't Assume

When a learning plan pairs vocabulary lists with reading passages:
- **Always verify alignment** before claiming "read what you just memorized" as a value proposition.
- Extraction method: parse each day's word list from the vocab source, search all 40 reading passages for each word, compute match rate.
- A match rate < 20% means the two components were authored independently. Be honest with the parent: this is "vocab study + parallel reading," not "vocabulary-embedded reading."
- The mode still works pedagogically (multiple exposures to the same word across different contexts over time), but the immediate-gratification pitch ("5 minutes later, you'll see it!") is false and will erode trust.
- For truly embedded reading: rewrite passages to force 5-6 target words per passage. But accept that forcing 10/10 per passage produces stilted, unnatural text. 5-6 is the sweet spot.

## Pitfalls

- **python-docx merge drops tables:** Copying paragraphs via `doc.paragraphs` silently skips all tables. Always iterate `element.body` children to capture both `w:p` and `w:tbl` elements in order. This is the #1 cause of "口算题目缺失" bugs in merged files.
- **Scattered daily files:** 9 individual files per day (口算+语文×3+英语×4+数学) overwhelms parents at print time and kids at desk time. Always consolidate into one merged file per day.
- **Over 4 mandatory blocks for ages 8-12:** The child will complete 4 but resent 5+. Extra items should be "bonus" or merged into existing blocks.
- **Mixed-discipline blocks:** Putting "Chinese reading + Math drill" in one block forces a subject switch mid-block. Keep blocks single-discipline.
- **Chinese as one undifferentiated block:** Chinese for Grade 4-5 requires three distinct sub-activities with different cognitive demands: 基础积累 (mechanical recall), 阅读 (comprehension), 背诵 (memorization). Grouping these into "语文60分钟" without structured sub-rotation leads to gaps. The sub-blocks should rotate skill types (6 types for 基础积累, 3 text types for 阅读, 2 for 背诵) to prevent monotony and ensure full coverage.
- **Skipping diagnostic before designing Chinese curriculum:** Always compare the plan against an actual test paper from the target grade. Chinese test papers for 四升五 are typically ~40% 基础积累 (拼音写词/字音字形/成语/修改语段/句式), ~5% 修改符号, ~55% 阅读 (记叙文+说明文+非连文本). A plan that only covers 阅读 will miss nearly half the points.
- **Same-day electronic rewards:** The fastest path to rushed work and learned helplessness. Always defer to next day.
- **No failure tolerance:** Requiring 4/4 every day → first miss → "today is ruined" → rest of day abandoned. Set threshold at 75%.
- **Evening block stacking:** Piling 4+ tasks into the 8-9pm slot is the highest-collapse zone. Keep evening to 2 items max, one passive + one parent-led.
- **Ignoring the BDNF window:** The 30 min after exercise is the best memory consolidation time of the day. Don't waste it on free play — use it for 15-20 min of retrieval practice with the parent.
- **Making exercise a checkbox:** For sporty kids, this backfires. It's part of life, not a task.
- **No weekly rhythm:** 7 identical days = burnout by Week 3. Always add a lighter day and a rest day.
- **Forgetting life anchors on the chart:** Lunch, dinner, and free time should be visible as gray reference lines, not as tasks. They provide rhythm without adding checkboxes.
- **Parent signature as punishment:** The evening check-in must end with a positive word, not criticism. The signature is a bookend, not a verdict.
- **Updating one subject's diagnostic but not the others:** When Chinese gets a comprehensive diagnostic overhaul, English and Math diagnostics must be updated in the same pass (or explicitly flagged as TODO). Mismatched diagnostic quality across subjects leads to uneven targeting. All three subjects should have 100-point diagnostic tests with parent scoring guides that map weak areas to specific practice days.
- **Reference materials left unintegrated:** Folders like `作文范文精选/` or `语法要点30讲/` that sit in `参考资料/` but never appear in daily practice files are worse than useless — they create confusion and take up mental space. After designing the daily curriculum, audit every reference folder and either integrate it, remove it, or explicitly label it as optional. The user WILL ask "did this get included?" — be able to answer yes for everything that survived cleanup.
- **Pinyin-English combined references:** For Grade 4 students still confusing pinyin and English alphabet sounds, any reference that shows both systems side-by-side (e.g., "拼音英语对比表") is actively harmful. Remove the English half and keep only pure pinyin reinforcement.
- **Deleting source files without checking backups:** Before bulk-deleting old files from weekly folders, verify they exist in a backup location (desktop `shanghai-exams/`, `reading-practice-60days-docx/`, etc.). The `shutil.rmtree` cleanup pattern should be preceded by a backup check. Original curated content (e.g., 60-day reading passages with 2 passages per day) is irreplaceable — AI-generated replacements will be noticeably lower quality and the user WILL notice.
- **Claiming vocab-reading alignment without verification:** When a plan pairs daily vocabulary lists with reading passages, never assert "you'll see the words in the reading" without verifying. Extract word lists from vocab files, grep across all reading passages, and compute the actual match rate. A 10% match rate (typical when vocab and reading are independently authored) means the pitch is false — honest framing builds more trust than an incorrect promise. The materials still have value as parallel tracks, just not as an embedded-review system.\n- **Generating new content when originals exist:** Never generate new reading passages or worksheets from scratch when original high-quality ones exist somewhere on disk. Search broadly (`os.walk` across desktop, backup folders like `shanghai-exams/`, `reading-practice-60days-docx/`) before concluding content is gone. The user's standard is real curated material — AI-generated passages tend to be longer, meandering, and ask vague questions. When the user says "质量不行" or "出的专业点," the correct response is to find and restore originals, not to try harder at generation. Original content always wins. This applies especially to: 60-day reading comprehension sets (2 passages per day, professionally edited), curated 口算 problem banks, and teacher-prepared grammar exercises.

## English Curriculum Design Checklist

When designing or reviewing an English summer plan for 四升五 (Grade 4→5, Oxford Shanghai edition):

1. **Get a real test paper first** — OCR it and map every question type to the plan's coverage
2. **English test paper OCR strategy**: Pix2Text fails badly on English+Chinese mixed test papers (garbage output). Use Tesseract with `-l eng` on grayscale-enhanced (2x resize) images instead. Output is readable but imperfect.
3. **Grammar is ~50% of the exam** — check for these 9 key grammar points:
   - 一般现在时 (do/does, have/has, third-person singular)
   - 现在进行时 (am/is/are + V-ing)
   - 介词 (in/on/at/under/behind)
   - 特殊疑问句 (What/Where/When/Whose/How many)
   - 词性转换 (n→adj, n→n's, num→ordinal: noise→noisy, music→musical, nine→ninth)
   - There be 句型 (There is/are, Is/Are there, How many...are there)
   - 祈使句/否定句 (Don't..., Let's..., Please...)
   - 连词成句
   - 改写句子（单复数转换、划线提问）
4. **Vocabulary should be topic-organized** — 学校/家庭/食物/动物/身体/天气/节日/日常活动/职业/自然, 10 words/day
5. **Reading needs 3 text types** — 短文阅读（60-100词）+ 非连续性文本（课程表/天气图表/海报/菜单/地图）
6. **Writing progression**: First 10 days = 模板填空仿写, Last 10 days = 命题写作 with prompt words
7. **Daily English = 4 files (60 min)**: 词汇(15') + 语法(25') + 阅读/写作交替(20')
8. **Grammar rotates 8 types × 5 cycles** over 40 days, spiraling complexity
9. **Generate matching answer keys** — vocabulary (word lists), grammar (answer by day), reading (choices+T/F+fill), writing (model essays)
10. **Reading passages MUST be from real 题库** — never AI-generate English reading passages. Source from: 道客巴巴真题, 昂立教育/绿光少儿教育 test papers, 英语范文 (adapted as reading), and any existing materials in `shanghai-exams/`. AI-generated passages are noticeably lower quality (correct grammar but vague questions, unnatural flow) and the user WILL reject them. Search `os.walk` across the entire desktop before concluding no real passages exist.
11. **Repetition is acceptable for D-level**: If only 20-25 real passages are found for a 40-day plan, using each 1.5-2x with different question focus (first pass: comprehension, second pass: vocabulary + retelling) is pedagogically valid. Fluency through re-reading beats variety through AI-generated filler.

### Grammar Alignment: 30 Lessons → 40 Days

When a reference grammar book has N lessons and you have M practice days (M > N):

```
Days 1..N:     One lesson per day, in order
Days N+1..M:   Review cycles, combining 3 lessons per day
```

For 30 lessons over 40 days: Day1=Lesson1, Day2=Lesson2, ..., Day30=Lesson30, Day31=Lessons 1+2+3, Day32=Lessons 4+5+6, ..., Day40=Lessons 28+29+30.

Each file should have 8-10 real questions (not template placeholders), mixing 填空/选择/改错/连词成句. Include Chinese section headers + English content. Always regenerate the full set if the reference changes — partial updates create alignment bugs.

### Reference Materials: Integrate or Remove

Reference materials sitting in `参考资料/` folders that are NOT woven into daily practice are dead weight. They create confusion (parents see them and wonder if they should be used) and risk (a child picks up a mixed pinyin-English reference and gets confused).

Rule: For every reference folder, ask "Does this appear in at least one daily practice file?" If not, either:
- Integrate it (generate daily snippets, align exercises to it)
- Remove it (delete the folder)
- Explicitly label it as "课外阅读/周末选做"

This session's examples:
- `语法要点30讲` → integrated by rewriting 40 grammar files to align (Days 1-30 = one lesson, Days 31-40 = review triples)
- `作文范文精选` → integrated as daily 作文积累 snippets (5 min/day, rotating through 写人→写事→写景→状物→修辞→考场技巧)
- `拼音英语速成方案` → removed English parts, kept pure pinyin reinforcement (7-day program)
