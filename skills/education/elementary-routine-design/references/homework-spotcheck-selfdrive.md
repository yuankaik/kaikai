# Weekly Homework Spot-Check + Self-Drive Framework

When a child's homework quality is poor (e.g., 60-point exams despite completing homework at school self-study),
the root cause is almost always "feedback断裂" — the child completes work but never receives quality feedback.
No one checks whether "done" = "correct."

## Hermes Spot-Check Workflow

### When homework is available

1. Parent sends photos of last week's homework via WeChat
2. Hermes uses vision_analyze to identify errors
3. Hermes generates 3-5 oral quiz questions (口头, NOT written)
4. Parent asks child on Sunday (15 min)
5. Child explains reasoning → pass or retry next week

### When homework is collected by school

1. Parent sends photo of textbook chapter/unit title
2. Hermes generates quiz questions from known knowledge points
3. Same oral question format

### Why oral, not written

- No writing = no resistance (consistent with 佳乐's "动作越少越能坚持" rule)
- Oral explanation verifies true understanding vs. copied answers
- 15 minutes is within attention span for Grade 5

## When to Consider External Classes

### 晚托班 Red Flags (from zhihu consensus)

- "辅导那是不可能的" — tutoring is impossible; teachers are underpaid
- "环境嘈杂，破坏专注力" — noisy environment destroys focus
- Risk of teachers writing answers FOR children
- Core problem: 晚托班 = 看娃+管饭+交差, NOT quality supervision

### What to Look For Instead

Search for "小学作业一对一辅导" or "小班作业精辅":
- Teacher-to-student ratio ≤ 1:5
- Post-homework: check + explain errors + strengthen weak areas
- Weekly text feedback to parents
- Trial week available

## When the Child Resists Test Papers

- Do NOT force test papers (zhihu consensus: 112 votes: "过量盲目刷题容易引发抵触")
- "不刷题，只跟错题死磕" — fight errors, not volume
- Wait until first unit test ≥ 75 before introducing test papers
- Frame test papers as "treasure maps" (宝藏地图) — finding gaps, not testing

## Spot-Check Question Format (3 Subjects × ~4 Questions Each, 15 min Total)

### Math (3-4 questions, 5 min)

| # | Type | Example | Tests |
|---|------|---------|-------|
| 1 | 退位减法 | "35-28 等于多少？讲一遍你怎么算的" | Step reasoning |
| 2 | 乘法口诀 | "7×8 等于多少？那 56÷7 呢？" | Automatic recall |
| 3 | 数位对齐 | "325-279，你先算哪一位？" | Vertical calculation logic |
| 4 | 应用题变式 | "100块买28的笔和35的书，剩多少？" | Word→equation translation |

### Chinese (4 questions, 5 min)

| # | Type | Example | Tests |
|---|------|---------|-------|
| 1 | 听写辨字 | "guī lǜ，规是哪个规？律是哪个律？" | Recognition vs. writing gap |
| 2 | 形近字 | "笼和茏有什么区别？罩的上面是什么？" | Detail discrimination |
| 3 | 近义词 | "灿烂还能换成什么词？宽阔呢？" | Vocabulary depth |
| 4 | 造句 | "用笼罩和恢复各说一句话" | Real understanding |

### English (4 questions, 5 min)

| # | Type | Example | Tests |
|---|------|---------|-------|
| 1 | 三单规则 | "He ___ (go) to school. 填 go 还是 goes？为什么？" | Grammar reasoning |
| 2 | 否定句 | "She likes apples. 改成否定句" | Does/doesn't + bare infinitive |
| 3 | 改错 | "They doesn't have lunch. 哪里错了？" | Subject-verb agreement |
| 4 | 口语变式 | "用英语说三件你每天做的事。至少一句用 he 开头" | Grammar→output transfer |

### Key Rules for Oral Spot-Checks

- **NEVER make the child write.** Oral only. Writing triggers resistance.
- **If the child can explain reasoning, the concept is solid.** Even if the answer is wrong but reasoning is mostly correct, that's partial credit.
- **If the child can't explain, the concept needs work.** Generate 1-2 more questions on same topic for next week.
- **One missed question ≠ the whole session is a failure.** 3 out of 4 correct = good week.
- **Praise what was right before addressing what was wrong.**

## Evening Routine Optimization for School Days

When a child has school self-study (晚自习) finishing homework, the evening cadence matters:

**BAD pattern (proven to fail):**
```
6:15 到家 → 吃饭 → 7:15 运动 → 8:30 洗漱 → 9:00 开始做作业 → 10:00 睡觉
```
Problem: Post-shower drowsiness hits, homework quality collapses. 9pm is the worst cognitive slot.

**GOOD pattern:**
```
6:15 到家 → 吃饭 → 6:45 做最难的一件(25min) → 7:15 运动 → 8:30 洗澡 → 8:45 背诵(20min) → 9:15 自由 → 9:45 关灯
```
Key: The single hardest task goes before exercise, when mental energy is highest. Recitation goes after shower when the body is relaxed but the brain is still alert.

**Acceptance rule:** If homework isn't done by 9:45, it doesn't get done. Sleep > one more problem. A child who knows the deadline is real works faster during school self-study. This is the清华爸爸's logic: early bedtime forces daytime efficiency.
