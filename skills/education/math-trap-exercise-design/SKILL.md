# 数学陷阱题设计模式

针对小学生常见数学概念混淆，设计"辨错型"练习题。核心原则：**不给答案让学生找，给错误算法让学生纠正。**

## 适用场景

- 面积公式与周长公式混淆
- 平行四边形"高"与"斜边"混淆
- 单位换算错误（m² vs m）
- 三角形"对应的高"选错
- 任何两个相似公式/概念的辨别

## 陷阱题设计公式

### 题型1：双问对比
同一图形，同时问面积和周长（或多给一个无关数据）。

```
例：平行四边形底10cm高7cm斜边8cm。
   (1) 面积 = ______
   (2) 周长 = ______
```
关键：学生必须判断两次——第一次选公式，第二次选数据。

### 题型2：辨错纠错
给出一个错误计算，让学生找错并改正。

```
例：长方形长8cm宽5cm。小明算"面积"写了 (8+5)×2=26。
    他算对了吗？为什么？正确答案是多少？
```

### 题型3：数据冗余
给的数据比需要的多，考察"选哪个"。

```
例：三角形底8cm高5cm，三条边分别为5cm、8cm、9cm。
    求：(1)面积 (2)周长
```
面积只用底和高，周长用三边——学生得自己判断用哪些数据。

### 题型4：概念判断题
不计算，只判断。

```
例：两个面积相等的三角形，一定能拼成一个平行四边形。对吗？
例：梯形上底和下底越长，面积越大。对吗？
```

## 5天专项练习结构（已验证，2026-07-30）

| 天 | 主题 | 题量 | 陷阱重点 |
|:---:|------|:---:|------|
| 1 | 单一公式掌握 | 8 | 引入公式，无陷阱 |
| 2 | 第二个公式 | 8 | 前一个公式与今天的新公式对比 |
| 3 | 第三个公式 | 8 | 三天公式汇总复习 |
| 4 | 面积vs周长辨错 | 8 | **全部陷阱题**，先判断求什么 |
| 5 | 综合+组合图形 | 10 | 混合所有，含生活应用 |

关键：Day4是核心——用一整天专门练"先判断再计算"。

## 设计铁律

1. 每天至少1道陷阱题（给了无关数据或错误算法）
2. 陷阱不藏到最后——前3题正常、中间3题有坑、最后2题综合
3. 答案写在家长卷，学生卷零答案
4. 15分钟内可完成——不增加负担
5. 概念判断题（不计算的）必须有——强迫"想"而不只是"算"
