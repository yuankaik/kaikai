## 一、平台搜索策略

### 1.1 道客巴巴 (doc88.com) — 最稳定平台

**可搜索的内容：**
- 通用练习关键词 → 效果好。例："小学 口算 天天练"、"沪教版 语文 阅读理解 四年级"
- 特级教师名字 → 能找到教学理念/课堂观察，找不到学生练习题
- 名师姓名 → 返回论文摘要、读后感、教学案例（非练习册）

**搜不到的内容：**

- 真实学生练习册 → 平台上是文档分享，培训机构系统教材不会上传

- 下载完整文档需登录+积分

## 二、自建练习库（当平台不可用时）

### 2.1 数学练习库结构

覆盖120个知识点（沪教版1-4年级），每个知识点5道练习题 + 答案。

生成方法：
1. 基于诊断表的知识点编号和题型格式
2. 每题独立设计参数（避免模板化）
3. 配合答案区（含算式/解释）
4. 用 `chinese-pdf-generation` 技能转PDF

文件命名：`佳乐数学练习库-全四册.md` / `.pdf`

### 2.2 完整练习生成工作流（2026-06-25 重大更新）

**端到端流程：期末卷分析 → 缺口诊断 → 对标生成 → 合并为每日单文件。**

#### 2.2.1 试卷分析

用 Pix2Text OCR 读取试卷照片，提取题型、分值、考点分布。
Pix2Text 对中文试卷效果好（80-90%），英文混排试卷改用 Tesseract `-l eng` + PIL 预处理。
详见 `correction-ocr` 技能的英文试卷处理部分。

#### 2.2.2 缺口对照

将试卷考点与现有暑假计划逐项对照，找出零覆盖/弱覆盖板块。
本会话发现的典型缺口：基础积累零覆盖（看拼音写词/字音字形/成语/修改语段/说明方法）、非连文本零覆盖、英语零覆盖。

#### 2.2.3 40天轮换设计

**语文 8 板块（对标四升五期末卷）：**

| 板块 | 天数 | 轮换 |
|------|------|------|
| 看拼音写词语 | 8天 | Day 1,6,11,16,21,26,31,36 |
| 字音字形辨析 | 8天 | Day 2,7,12,17,22,27,32,37 |
| 成语典故 | 8天 | Day 3,8,13,18,23,28,33,38 |
| 修改语段+句式仿写 | 8天 | Day 4,9,14,19,24,29,34,39 |
| 说明方法+综合 | 8天 | Day 5,10,15,20,25,30,35,40 |
| 阅读理解 | 每日 | 记叙文/说明文/非连三轮换 |
| 背诵积累 | 每日 | 古诗(奇)/成语(偶) |
| 作文积累 | 每日 | 好词好句+仿写 |

**英语 4 板块（对标四升五期末卷，对齐语法要点30讲）：**
- 词汇：10词/天，主题轮换（学校/家庭/食物/动物/身体/天气/节日/日常/职业/自然）
- 语法：Day1-30逐讲对齐30讲，Day31-40每3讲综合复习
- 阅读：20篇短文 + 非连文本，隔天轮换
- 写作：20篇（仿写→命题），隔天轮换

**口算（数学）：**
- ~39题/天，15分钟可完成（D等学生1分钟3题≈45题上限，留余量）
- **每个子模块按比例取样**（不是取前N题）：如万以内加减法4个子模块，每模块取~10题 = 40题覆盖全部类型
- 原版100题结构 = 热身 + 核心训练 + 核心训练 + 应用，保持此结构

#### 2.2.4 批量生成 DOCX

用 `execute_code` + `python-docx`。关键模式：

```python
from docx import Document
from docx.shared import Pt, Cm
from docx.oxml.ns import qn

# 设置中文字体
style = doc.styles['Normal']
style.font.name = '宋体'
style.element.rPr.rFonts.set(qn('w:eastAsia'), '宋体')
```

内容用 Python dict/list 定义，循环生成。

**口算特殊处理：**
- MD源文件有两种格式：table格式（`|序号|题目|答案|`）和list格式（`1. 题目`）
- 必须兼容两种格式的解析
- 子模块按比例分配题目数：`每个模块取 = max(1, int(总目标 × 该模块题数 / 全部题数))`
- 学生卷：纯题目，无答案速查表，无题号占位列，2列紧凑排版，行距增大
- 家长卷：题目+答案4列

#### 2.2.5 合并为每日单文件

**原则：** 每天1份学生卷 + 1份家长卷。不再分散多个文件。

**合并技术要点（关键！）：**

```python
from docx.oxml.ns import qn

def append_docx(dst, src_path):
    """复制整个DOCX内容（段落+表格）到目标文档"""
    src = Document(src_path)
    body = src.element.body
    para_list = list(src.paragraphs)
    tbl_list = list(src.tables)
    pi = ti = 0
    
    for child in body:
        if child.tag == qn('w:p') and pi < len(para_list):
            # 复制段落
            sp = para_list[pi]; pi += 1
            p = dst.add_paragraph()
            for run in sp.runs:
                r = p.add_run(run.text)
                r.bold = run.bold
                r.font.size = run.font.size
        elif child.tag == qn('w:tbl') and ti < len(tbl_list):
            # 复制表格（含单元格内容）
            copy_table(dst, tbl_list[ti]); ti += 1
```

⚠️ **只复制 `doc.paragraphs` 会丢失表格！** 必须遍历 `element.body` 的 `w:p` 和 `w:tbl` 子元素。

**答案过滤：** 学生卷合并时过滤答案提示段落（"如果第X题错了""用铅笔画出"等关键词）。

**文件锁定处理：** WSL写入Windows桌面文件时，Word打开的文件会PermissionError。先 `os.remove` 再写入。

#### 2.2.6 诊断工具同步生成

为三科各生成一份综合检测表（学生卷100分 + 家长评分指南）：
- 试卷结构对标期末卷考点
- 家长指南含评分标准 + 诊断对照表 + 薄弱→练习映射
- 暑假开始前花2-3天摸底，暑假结束时复测

#### 2.2.7 口算专项要点

- **题量：** ~40题/天，15分钟。100题对于D等学生不可能完成（1分钟3题≈33题上限）
- **采样：** 每个子模块等比例取，保证题型多样性。取前N题=只练热身
- **排版：** 2列紧凑，无题号，无答案速查表（答案全在家长卷）
- **格式兼容：** MD源有table格式和list格式两种，必须都支持

### 2.3.1 词汇掌握率检测表（带勾选框）

在词汇总表基础上，生成可打印的掌握率检测表。每词配 ✓（已掌握）/ ✗（未掌握）/ △（半熟）三列勾选框。

**生成方法：**
1. 用 Python 脚本直接生成 HTML（含 CSS 样式）——推荐，比 MD→HTML 更灵活
2. 表格列：序号 | 英文 | 中文 | ☐✓ | ☐✗ | ☐△（☐ 用 Unicode □ 字符，打印后手写勾选）
3. 每册独立 h2 + `page-break-before: always`
4. 每册末行：`本册共 N 词 | 掌握：__/__ | 掌握率：__%`
5. 用 `weasyprint.HTML().write_pdf()` 直接转 PDF（无需经过 MD）
6. 文件命名：`词汇掌握率检测表.html` / `.pdf`（输出 ~850KB）

**CSS 关键：** 勾选列 `width: 32pt; text-align: center; font-size: 14pt`（便于打印后看清和手写）。3-5年级加红色 `[2026新版]` 标记。

### 2.3.2 错词追踪与短文练习系统

**完整闭环：** 打印检测表 → 佳乐逐册填 ✓✗△ → 拍照发微信 → AI 用 vision 识错词 → 存入 JSON 数据库 → 生成含错词的英语短文 → 打印练习 → 复测 → 标记掌握

**文件结构（放 `shanghai-exams/错词追踪/`）：**
- `workflow.md` — 完整流程说明（6步 + 拍照要求 + 练习步骤）
- `错词追踪.json` — 错词数据库

**JSON 结构：**
```json
{
  "records": [
    {"date": "2026-06-22", "grade": "5A", "source": "检测表拍照",
     "words": [{"en": "typhoon", "cn": "台风", "status": "new"}]}
  ],
  "summary": {"total_wrong_ever": 0, "currently_new": 0, "currently_practicing": 0, "currently_stubborn": 0, "total_mastered": 0}
}
```

**状态流转：** `new`（新发现）→ `practicing`（已练短文）→ `mastered`（复测通过）/ `stubborn`（3次未掌握）

**Vision 识别流程：** 用户发照片 → `vision_analyze` 读取 ✓/✗/△ 标记 → 提取所有 ✗ 和 △ 的词 → 追加到 JSON 的 records 数组 → 更新 summary 计数 → 返回识别的错词清单供确认

**短文生成：** 80-150词，每篇涵盖5-10个目标错词。内容贴合佳乐兴趣（运动、动物、冒险）。附中文翻译和重点词标注。

> 完整 HTML 模板、CSS 样式、JSON schema、vision prompt 见：`references/vocab-tracking-workflow.md`

## 五、常见陷阱

- 道客巴巴品牌词被屏蔽 → 用通用替代词，不要反复尝试品牌名
- 道客巴巴文档页无文本 → 放弃提取，从搜索结果摘要获取信息
- 百度文库文档页用 Canvas 渲染（非 HTML DOM）→ 文字不可程序提取，必须另找来源
- 知乎 IP 频率限制 403（`code: 40362`）→ 不重试，换其他来源或自建内容
- 夸克save API永远401 → 走浏览器手动保存，不浪费自动化时间
- 平台封锁趋于加剧 → 不等，直接自建内容
- 用户说"和时间赛跑" → 立即切换为生成模式，不纠结爬取
- WSL 网络不通（`Network is unreachable`）→ 用浏览器工具替代 curl/Python HTTP；浏览器搜索百度可行但抓取深度内容困难

## 六、书写提速（小学生字迹潦草问题）

### 6.1 问题本质

10岁左右（4-5年级）字迹变潦草是普遍现象。原因不是"态度变差"，而是：
- 3-4年级识字量和作业量同时暴增
- 老师批改重点从"字好不好"转向"题对不对"
- 孩子在速度压力下被迫放弃质量控制

**核心原则：用户认为字体演变本就是实用驱动（毛笔→钢笔→圆珠笔→键盘），拒绝"小学只能练楷书"的教条。目标不是书法美观，是又快又认得清。**

### 6.2 丁迪蒙方法

丁迪蒙，上海大学中文系副教授，上海书协会员。专攻实用硬笔快写（非传统书法），核心主张与用户一致。

- 《趣味硬笔行楷速版》（2018年上海大学出版社）— 她是行楷派，但不适合10岁直接用
- 《365天轻松学好硬笔字》（2004年，上海科学技术文献出版社，192页）— 方法论："先做零件再装配"，先练笔画快写→再拼字
- **图书可获得性**：❌ 网上无免费PDF。小众学术出版社，印量小，未被盗版。淘宝/当当买纸质版约25元。

### 6.3 对佳乐（10岁/有5级硬笔底子）的建议

**不走纯行楷，走"楷书快写 + 丁迪蒙方法论"中间路线：**

| 材料 | 用途 |
|------|------|
| 丁迪蒙《365天轻松学好硬笔字》 | 学节奏感——"先零件后装配" |
| 任意硬笔楷书快写字帖 | 在楷书框架内允许自然连笔（如横折不断开） |

**每天15分钟训练法：**
1. 前5分钟：单笔画快写（横/竖/撇/捺各20个，求快不求完美）
2. 后10分钟：抄课文计时。目标：比昨天快1字，每个字认得出。

**关键洞察：不是换字体，是改变书写节奏。** 楷书是一笔一断的节奏，快写是笔画间有流动感。佳乐有底子，两周见效。不要另学一套新字体——在同一套楷书框架内练速度。

### 6.4 行业共识速查

- **教育部标准**：5-6年级要求"熟练写正楷"，不要求行楷
- **荆霄鹏**（主流小学生字帖作者）：被描述为"楷书的快写版，保留法度"
- **吴玉生**：纯行楷门槛高，适合初中以上
- **知乎/百度共识**："字形适当放小可提速"、"控笔训练：横向手腕动、竖向手指动"

### 6.5 4周训练计划模板

当用户要求为小学生设计快写训练方案时，用此结构：

| 周 | 阶段 | 重点 |
|:---:|------|------|
| 1 | 笔画过关 | 7天，每天1个基本笔画，慢写→快写对比 |
| 2 | 高频字过关 | 35个最常用字循环练，建立快写肌肉记忆 |
| 3 | 连笔意识 | 楷书框架内允许转折处不抬笔（横折/撇捺/点横连笔） |
| 4 | 实战应用 | 把快写用到日常作业中 |

**每日流程（10-15分钟）：**
```
2分钟 单笔画预热（翻书找当天对应页）
3分钟 慢写一行（正常速度，写到佳乐自己满意）
5分钟 快写同一行（秒表计时，只要求字认得出）
```

**进度追踪系统：**
- 每日打卡表（完成✅ / 字数 / 用时 / 认不出数 / 心情😊😐😟）
- 每周日极限挑战（5分钟抄课文，统计字数+潦草数）
- 综合分公式：字数×2 - 潦草数×5
- 进步曲线图：横轴周次，纵轴综合分，四个点连成线，贴墙上
- 核心激励：只跟自己上周比，不跟别人比

**家长操作要点：**
- ✅ 手机秒表计时，让数字在跑（增加挑战感）
- ✅ 快写结束先夸速度，再轻描淡写说认不清的字
- ✅ 周末挑战成功必有奖励
- ❌ 不纠正笔画角度（快写不追求书法标准）
- ❌ 不在快写时喊停重写（打断节奏比写丑更糟）
- ❌ 不加量（每天最多15分钟）

**输出格式：** .md + .pdf（用 chinese-pdf-generation 技能），包含完整的四周计划表、每日打卡追踪表、进步曲线图、家长操作要点。
