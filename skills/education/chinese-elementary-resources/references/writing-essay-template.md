# Writing Model Essay Template

For Grade 5 (adaptable to Grades 3-4).

## Per-Essay Format

```markdown
## <序号>. 《<作文标题>》

<400-600字正文>

---

【写作框架】
<文章结构拆解，2-4行>

【好词好句】
- <词语1>：<文中用法>
- <词语2>：<文中用法>
- <句子1>（精彩句子摘录）
- <句子2>

【背诵要点】
- 为什么值得背：<理由>
- 考试可套用题目：<列举2-3个适配题目>
```

## Seven Writing Categories with Templates

### 1. 写人类 (Character)
Structure: 外貌(1段) → 典型事例(2段，详写) → 品质升华(1段)

Key phrases: 炯炯有神, 和蔼可亲, 孜孜不倦, 无微不至

### 2. 记事类 (Narrative)
Structure: 起因(1段) → 经过(2段，占60%) → 结果(1段) → 感悟(1段)

Key phrases: 记忆犹新, 受益匪浅, 恍然大悟, 刻骨铭心

### 3. 写景类 (Scenery)
Structure: 总体印象(1段) → 按空间/时间详细描写(2段) → 情感升华(1段)

Key phrases: 美不胜收, 心旷神怡, 流连忘返, 如诗如画

### 4. 状物类 (Object)
Structure: 外形特征(1段) → 功能用途(1段) → 情感联结(1段)

Key phrases: 爱不释手, 栩栩如生, 小巧玲珑, 古色古香

### 5. 想象类 (Imagination)
Structure: 设定(1段) → 冒险/变化(2段) → 回归/感悟(1段)

Key phrases: 天马行空, 不可思议, 异想天开, 身临其境

### 6. 读后感 (Book Report)
Structure: 引(1段，引用原文) → 议(1段，分析) → 联(1段，联系自己) → 结(1段，总结)

Key phrases: 受益匪浅, 发人深省, 感同身受, 茅塞顿开

### 7. 书信日记 (Letter/Diary)
Structure: 称呼 → 正文(事件+感受) → 祝福语 → 署名日期

Key phrases: 见字如面, 展信佳, 光阴似箭, 日月如梭

## Five Opening Methods

1. **开门见山**: 直接点题。例："我的妈妈是一个普通的会计，但在我心中，她是最不平凡的人。"
2. **设问开头**: 用问题引入。例："你有没有一个让你又爱又恨的人？对我来说，那个人就是我的同桌张小凡。"
3. **环境渲染**: 描写环境烘托气氛。例："窗外下着淅淅沥沥的小雨，我望着窗外出神，不由得想起了那个同样下着雨的下午……"
4. **对比引入**: 用对比制造张力。例："别人家的妈妈温柔体贴，我的妈妈却像个'女汉子'。"
5. **引用开头**: 引用名言诗句。例："'谁言寸草心，报得三春晖。'每当读到这句诗，我就想起了妈妈。"

## Five Closing Methods

1. **总结全文**: "这就是我的妈妈，一个普通却伟大的母亲。"
2. **感悟升华**: "从这件事中，我明白了一个道理：真正的勇敢，不是不害怕，而是害怕之后依然选择前行。"
3. **首尾呼应**: 与开头形成闭环
4. **抒情结尾**: 表达强烈情感
5. **展望未来**: "我相信，只要坚持下去，总有一天……"
