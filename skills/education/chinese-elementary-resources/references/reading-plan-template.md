# 60-Day Reading Practice Plan Template

Copy and adapt this structure for any grade level (3-5).

## Directory Structure

```
<project-name>/
├── 00-总体规划.md
├── 第一阶段-综合训练总结.md
├── day_01/阅读练习.md
├── day_02/阅读练习.md
├── ...
├── day_60/阅读练习.md
├── 家长指南/家长完全指南.md
└── 错因追踪/错因追踪表.md
```

```markdown
---

```

## File Naming

- Days: `day_01` through `day_60` (zero-padded to 2 digits)
- Each day is a directory containing `阅读练习.md`
- Supporting docs at root level

## Theme Distribution

Distribute these themes across the 60 days:
- 校园生活 (school life)
- 家庭亲情 (family)
- 自然观察 (nature observation)
- 成长故事 (growing up)
- 寓言哲理 (fables)
- 人物品质 (character)
- 科普知识 (science)
- 传统文化 (traditional culture)

## Error Tags Reference

### 信息提取
- #找不到原文依据
- #信息遗漏
- #答非所问

### 词语理解
- #只解释词典义不联系上下文
- #词语替换判断不准
- #词义理解错误

### 原因题
- #原因找不全
- #因果关系错误
- #用自己的话而非文中

### 句子理解
- #只答表面不答深层
- #深层理解错误
- #遗漏关键词分析

### 人物品质/中心
- #只写品质不写依据
- #依据不匹配
- #中心概括空泛
- #只说内容不说道理

### 通用
- #答案不完整
- #只写关键词
- #语言不通顺
