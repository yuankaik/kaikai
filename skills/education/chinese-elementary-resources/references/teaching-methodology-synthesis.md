# Teaching Methodology Synthesis Template

Template for condensing teacher resource files into actionable 佳乐 methodology. Use when reading through shanghai-exams teacher materials.

## Extraction Targets

For each teacher, extract:
1. **Name + background** (one line)
2. **Core method** (3-5 keywords)
3. **Concrete classroom technique** (1-2 specific examples)
4. **佳乐 applicability** (how to use with D-level student)

### 阅读答题模板 (直接教佳乐)

| Question Type | Template |
|--------------|----------|
| 概括内容 | (时间)+谁+在哪+干了什么+结果 |
| 理解词语 | 本义是…，文中指…，表达了… |
| 赏析句子 | 用了[修辞]，写了[内容]，表达了[情感] |
| 体会感情 | 通过写…，表达了作者… |
| 联系生活 | 文中…→让我想到…→我感受到… |
