# 练习卷答案拆离技术：python-docx 批量拆分

## 场景

获取的练习材料（如60天阅读理解练习）通常题目和答案混在同一文件里。孩子一打开就能看到答案，材料等于报废。需要批量拆成「学生卷」（只有短文+题目）和「家长答案」（答案+解析+批改提示）。

## 技术要点

### 核心思路：内容分类 + 区段追踪

不用简单状态机（会卡在 parent 模式回不到 student 模式），改用：
1. **每段独立分类**：判断是否含有答案/评分/批改关键字
2. **区段追踪**：进入「家长批改提示」「孩子重写任务」区段后，整段跳过，直到下一个短文标记

### 父内容识别关键字（任一命中即跳过）

```
标准答案、依据段、评分点、常见错因标签、
家长批改提示、孩子重写任务、今日总结、明天预告、本日训练要点
```

### 区段头格式穷举（必须全部匹配）

教育材料里这些标题格式五花八门：
- `家长批改提示`（纯文本）
- `**家长批改提示**`（Markdown 加粗）
- `短文一家长批改提示`（合并格式）
- `短文一 · 家长批改提示`（带分隔符）
- `孩子重写任务：`（带冒号）
- `**孩子重写任务**`（Markdown 加粗）

清理策略：`text.replace('**', '').strip()` 后再匹配正则。

### 区段退出条件

进入 parent 区段后，遇到这些标记退出：
- `阅读短文一/二`、`短文一/二`
- `【第一篇】`、`【第二篇】`
- `今日总结`、`明天预告`、`本日训练要点`

### 格式保留

用 `copy_paragraph` 逐段复制，保留每个 run 的 bold/italic/size 属性：

```python
def copy_paragraph(src_p, dst_doc):
    p = dst_doc.add_paragraph()
    p.alignment = src_p.alignment
    for run in src_p.runs:
        r = p.add_run(run.text)
        r.bold = run.bold
        r.italic = run.italic
        if run.font.size:
            r.font.size = run.font.size
```

## 已验证的多格式兼容

此方案在 60 个文件中验证，覆盖至少 4 种不同排版格式：
- **Day 1-2**：`阅读短文一→题目→答案与解析→家长批改提示→孩子重写任务`
- **Day 3-7**：`短文一→题1→问题→标准答案→...→家长批改提示→孩子重写任务`（题与答案交错）
- **Day 8-49**：`短文一：《标题》→短文一 · 练习题→题+答案交错→短文一 · 家长批改提示→孩子重写任务`
- **Day 30-60**：`【第一篇】→阅读理解题→题+标准答案→家长批改提示→孩子重写任务`

## 常见坑

1. **「答案」标签不统一**：有的用 `标准答案：`，有的用 `第X题答案：`，有的用 `短文一标准答案`。用 `'标准答案' in text` 覆盖主要情况，少数遗漏不影响功能（答案已在父内容区段被跳过）。
2. **区段头被 Markdown 包裹**：`**家长批改提示**` 必须 strip `**` 后再匹配。
3. **区段退出不完整**：如果忘记在某个格式里添加退出条件，parent 模式会一直延续到文件末尾，吞掉后面的所有内容。测试时重点检查后半段短文是否还在学生卷里。
4. **不要用纯状态机**：一次进入 parent 模式后如果只在短文边界退出，会因为格式差异导致部分题目丢失。每段独立判断是更稳健的方案。
