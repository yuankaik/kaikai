### 舒尔特规则
- 只在开头和结尾两个位置，各3格，共6格/天
- 不要每个板块后都加——打断学习流
- 当前使用入门3×3（适合注意力差的10岁儿童）
- 字体Arial（数字清晰），18pt

## 数学题生成逻辑

### 槽1：竖式计算（5题/天，6天一循环）
- Day A: 加法竖式（进位）
- Day B: 减法竖式（退位）
- Day C: 乘法竖式 + 简便(25×N)
- Day D: 除法竖式
- Day E: 混合竖式（加减乘除各一）

### 槽2：脱式/混合运算（3题/天，4天一循环）
- 脱式计算基础 / 简便计算 / 分数 / 综合

### 槽3：应用题（3题/天，5天一循环）
- 归一购物 / 余数除法 / 几何 / 单位换算 / 综合

### 槽4：其他轮换（2题/天，6型轮换）
- 大数读写 / 分数 / 小数 / 几何 / 估算 / 验算

### 五上预习
- Day 1-20：完全不做（集中巩固基础）
- Day 21-40：每天3-5题小数乘除+解方程

## 已知Pitfalls

### 口算生成器边界bug
```python
# unit_a == 0 时空列表抛异常
# 修复：整十数时任意单数都进位
if unit_a == 0:
    b = random.randint(1, 9)
```

### 英语阅读粗体渲染
`**word**` 必须用 `add_bold_parse_text()` 解析为真实粗体runs，禁用纯 `add_text()`。

### 生成后内容缺失检查
- 阅读文字>300字/篇 ✅，149字模板 ❌
- 作文正文>300字 ✅，"朗读范文..."占位符 ❌
- 英语粗体词>0 ✅，`**word**` 星号 ❌

### Day编号偏移
如旧Day01已用，从Day40倒序改名到Day01（每文件+1），批量替换内部"Day N"→"Day N+1"和"第N天"→"第N+1天"。

### DOCX阅读提取
旧版备份中的短文用状态机提取（seeking→in_text→in_questions→skipping_answers），跳过"答案与解析"段落。支持3种格式：`阅读短文一：《T》`、`短文一：CAT`(标题下行)、standalone bold title。
