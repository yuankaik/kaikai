## 排程逻辑

- 按年级递进排列：低年级在前（Day 1-20: 1-2年级 → Day 80-100: 5年级）
- 均匀分布：133项 ÷ 100天 ≈ 1.33项/天
- 67天推1项，33天推2项
- 同类内容相邻（同年级古诗→文言→日积月累）

## 进度追踪

文件 `语文背诵进度.txt`：
```
行1: 当前天数 (1-100)
行2: 当前轮次 (1=首轮, 2=复习轮, ...)
```

Cron 每次运行：
1. 读进度 → 取 Day N 内容
2. 推送
3. day += 1
4. 若 day > 100 → day=1, round+=1
5. 写回进度文件
