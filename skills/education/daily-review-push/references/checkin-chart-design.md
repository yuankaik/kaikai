# 佳乐每日打卡表设计模式

> 完整方法论。当用户需要为佳乐设计/审查/简化每日作息打卡表时，按此文执行。
> 设计铁律：动作越少越能坚持。设计任何功能先问：佳乐要多做一个动作吗？是→砍掉。

---

## 第一部分：可持续性诊断框架

任何打卡表拿到手，先用以下 5 个硬指标过一遍：

### 指标1：认知切换次数

数一下一天内"换脑子"的次数（换学科、换设备、换房间都算一次切换）。
- 成人高效工作：6-8次/天
- 10岁孩子前额叶还在发育，切换成本是成人 2-3 倍
- **红线：12次以上必崩，10次以内安全**

### 指标2：最脆弱时段

找出全天唯一无监督+高诱惑时段（通常是下午孩子独自在家+Switch在侧）。
这个时段不能堆超过 2 项任务，否则必崩。

### 指标3：奖励与努力的匹配

```
总学习时长 ÷ 总娱乐时长 = 比例
```
- 2:1 ~ 3:1 是合理区间
- <2:1 家长不安心，>3:1 孩子不干

### 指标4：晚间块任务数

晚间（20:00以后）是全天最脆弱的学习时段。孩子已经累了，前额叶抑制能力降到最低。
- 晚间块子任务 ≤2 项
- >2 项三天内必抵触

### 指标5：奖励时机（小红书验证）

小红书/知乎/小花生共识：**"学习换游戏时间"当天兑现 → 第二天必然偷工减料。**
行为经济学上的「延迟折扣」倒挂——当奖励在学习之后立刻可获得，大脑把学习异化为"为了游戏而忍受的折磨"。

- ✅ **延期兑付**：今天的完成 → 明天的 Switch（小红书"海淀妈妈作息表"2.3万赞）
- ✅ **积点兑付**：5勾=1张游戏券，周末集中玩（小花生"学霸暑假计划"）
- ❌ **当天兑现电子产品** → 下午任务必然敷衍

## 第二部分：任务块设计原则

### 原则1：同类打包（不拆分）

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 早口算12min + 晚口算8min | 合并为晨间口算15min，一次练够 |
| 上午练字短练 + 晚上练字10min | 合并为上午练字15min |
| 语文阅读 + 英语阅读 各一块 | 语文类一上午全搞定 |

### 原则2：学科独占一块

语文、数学、英语各需要独立块。如果块数不够，优先砍弹性块而不是合并学科。

### 原则3：运动不一定打勾

对体育型孩子（佳乐），运动是享受不是负担。打勾反而把它变成任务。
→ 运动放弹性块：不打勾，默认完成。

### 原则4：标注自由时间

表上只写任务时间不写自由时间 → 孩子感觉全天被安排。
→ 在任务块之间标注灰色"自由时间"标签。

### 原则5：生活锚点

午饭(🍚)、晚饭不需要打卡，但表上需要出现（灰色小字），提供节奏参照。

### 原则6：≤4 个必须打勾块

研究和小红书共识：每天 ≤4 个必须任务块是可持续上限。4个块以上首周崩溃率超 50%。

## 第三部分：最终推荐方案

### 全天时间线（2026-06-23 定稿）

```
🌅 7:30-8:45   晨起        起床+早餐+口算15min
📖 9:30-10:45   语文        轻阅读+练字+好段积累（三合一）
🔢 11:00-11:35  AI数学      35min
🍚 11:30-12:30  午饭        灰色锚点，不打勾
   12:30-14:00  自由时间
🇬🇧 14:00-15:15  英语        单词10个+My Weird School阅读+专项轮换
🎮 15:30-17:00  Switch      (昨天完成≥3块的奖励，家长控制锁死窗口)
🍚 17:30-18:30  晚饭        灰色锚点
😴 18:30-19:00  真正休息    消化高峰，放空
🎧 19:00-19:25  听力+错题   被动输入（饭后60分钟OK，运动前做）
🏀 19:30-20:30  运动        篮球60分钟（弹性块，不打勾）
🚿 20:30-20:45  洗澡
⚡ 20:45-21:05  快速复盘    提取练习+家长检查（运动后BDNF黄金窗口）
🛀 21:05-21:30  睡前自由
😴 21:30        睡觉
```

### 周循环（6+1模式）

| 日 | 模式 | 说明 |
|----|------|------|
| 周一~五 | 全勤 | 按上方时间线执行 |
| 周六 | 轻量日 | 仅语文轻阅读15min + 自由运动，下午Switch自由（当天给） |
| 周日 | 完全休息 | 全天自由，Switch随便玩 |

### 必须块统计

| # | 块 | 性质 | 时间 | 内容 |
|---|-----|------|------|------|
| 1 | 晨起 | 必须 | 7:30-8:45 | 口算15min |
| 2 | 语文 | 必须 | 9:30-10:45 | 轻阅读+练字+好段积累 |
| 3 | AI数学 | 必须 | 11:00-11:35 | 35min |
| 4 | 英语 | 必须 | 14:00-15:15 | 单词+阅读+专项 |
| 5 | 晚间 | 必须 | 19:00-19:25 | 听力+错题(家长) |
| + | 运动 | 弹性 | 19:30-20:30 | 不打勾，默认完成 |

实际上 5 个必须块，但晚间块极短（25分钟）且运动不打勾 → 孩子心理感受是"4个主要任务+运动去玩+睡前家长陪着过一下"，不超负荷。

## 第四部分：奖励系统设计（次日兑现版）

### 核心方案

```
┌──────────────────────────────────────────────────────┐
│  今天的快速复盘（20:45）= 决定明天的 Switch            │
│                                                      │
│  保底 Switch 45分钟（明天）：完成≥3/5必须块            │
│  加时 Switch 45分钟（明天）：完成全部5块+无作弊         │
│                                                      │
│  ⚠️ Switch 严格只在 15:30-17:00 窗口开放               │
│    通过 Switch 家长控制 App 设置时间窗口，机器自动锁死  │
│                                                      │
│  本周六 Switch 全天自由（当天给，不限时）              │
│  本周日 Switch 全天自由（当天给，不限时）              │
└──────────────────────────────────────────────────────┘

累计积分系统（防奖励贬值）：
  每天满勾 = 1颗⭐
  5颗⭐ = 周末选餐馆 / 选活动
  20颗⭐ = 解锁限定新游戏 / 买皮肤
```

### 为什么是次日兑现？（小红书第一教训）

1. **下午英语不再心猿意马** — 孩子知道今天没有Switch，不赶工
2. **快速复盘时孩子认真** — 今晚的勾决定明天的Switch，有切肤之痛
3. **周一动力最足** — 周末自由两天，周一新鲜感上线
4. **避免"学习=为了游戏而忍受"的心理异化**

### 为什么是周循环？

小红书最热门的两类暑期表：
- 每日打卡表 → 自律强的孩子
- **周循环表**（更流行）→ 绝大多数孩子

60天暑假每天一样，第10天心理疲劳。6+1模式打破单调，周日成为"心理重置日"。

## 第五部分：快速复盘（运动后家长检查）

### 为什么在运动后？

运动结束 → BDNF 飙升 → 海马体兴奋 → 持续约 30-60 分钟。
这是记忆巩固的黄金窗口。提取练习（retrieval practice）在此窗口效率最高。

### 20分钟流程（20:45-21:05）

| 顺序 | 项目 | 方式 | 时长 | 查什么 |
|------|------|------|------|--------|
| 1 | 口算抽查 | 挑2道早上做的，让他重讲思路 | 2min | 没懂还是真会 |
| 2 | 好段复述 | "今天积累了哪句话？背给我听听" | 2min | 输入进脑子了吗 |
| 3 | 英语单词闪 | 10个词随机抽4个，念中文他说英文 | 3min | 短期记忆→提取 |
| 4 | My W.S.趣事 | "今天那章讲了什么好玩的？" | 2min | 真读了吗 |
| 5 | 费曼讲数学 | "今天AI数学教了什么？用你的话讲" | 3min | 真懂假懂一秒暴露 |
| 6 | 错题重看 | 翻开错题本快速扫一遍 | 2min | 昨天的坑填了吗 |
| 7 | 打勾+签字 | 过一遍完成情况，表上签字 | 1min | 一天句号 |

**关键态度：不是质问，是聊天。** "今天My Weird School讲了什么好玩的？" 不是 "你给我复述一遍课文"。语气对了孩子开口，语气不对孩子沉默。

**费曼法精髓：** 孩子讲不出来 → 不说"你怎么没学会"，说"有意思，明天再看看这个"。惩罚→闭嘴，好奇→开口。

### 如果漏了一块

不在 20:45 补做。第二天 Switch 保底减到 30 分钟。不当天惩罚、不当场发火。

## 第七部分：饭后学习可行性

### 饭后认知曲线

| 饭后时间 | 脑供血状态 | 适合做什么 |
|----------|-----------|-----------|
| 0-30分钟 | 消化高峰，最困 | ❌ 啥都别做 |
| 30-60分钟 | 逐渐恢复，轻认知OK | ✅ 被动输入型（听力） |
| 60分钟后 | 基本正常 | ✅ 主动思考 |

### 我们的设计

- 19:00-19:25（饭后60-85分钟）：英语听力 + 错题复盘
  - 听力是被动输入 ✅
  - 错题复盘是对话不是解题 ✅
  - 时长仅25分钟 ✅
- 放在运动前，利用运动后 BDNF 窗口做主动提取

## 第九部分：生成模板

见 `templates/checkin-chart.html` — 王牌钓手主题、4+1结构、海洋配色、可打印PDF。

转PDF：
```bash
python3 -c "
import weasyprint
pdf = weasyprint.HTML(filename='checkin-chart.html').write_pdf()
open('output.pdf', 'wb').write(pdf)
"
```

前提：`pip install weasyprint` + `sudo apt install fonts-noto-cjk`。WeasyPrint + Python 3.14 可能需要 `pip install --break-system-packages --upgrade Pillow` 修复 `_imagingcms` 导入错误。
