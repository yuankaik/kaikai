# 英语嵌入阅读生成模式

## 适用场景

为佳乐生成个性化英语词汇学习材料：每天 10 个生词 + 嵌入式短文 + 艾宾浩斯复习。

## 数据源

- `shanghai-exams/牛津英语1-5年级词汇总表.md` — 1044 词，含年级/单元标注
- 摸底照片（手机拍JPG）— vision 采样确认"会/不会"规律

## 摸底识别策略

**不需要逐页 100% 识别。** 采样 8-12 张关键页确认规律即可：
- 前几页（1A/1B 基础词）→ 确认低年级掌握情况
- 中间页（3A/3B）→ 确认中年级
- 后几页（4A/4B/5A）→ 确认高年级

典型规律（佳乐实测）：
- 具体名词（body parts, school items, food, colors）→ 基本会
- 抽象形容词（helpful, brave, shy, polite）→ 几乎全不会
- 动作词/社交词（draw, write, buy, hello, goodbye）→ 大部分不会
- 节日/文化词（Spring Festival, Christmas）→ 几乎全不会

## 词表编排

400 词 / 40 天 × 10 词/天，按年级递进：
```
Day 1-5:   1A/1B 基础（问候、家庭、身体、颜色、数字）
Day 6-10:  2A 词汇（学校、动作、动物、天气）
Day 11-15: 2B/3A 混合（衣物、食物、时间、感官）
Day 16-20: 3A/3B（学校科目、场所、情感、四季）
Day 21-25: 4A（方位介词、性格形容词、国家、职业）
Day 26-30: 4B（旅行、城市、购物、日常活动）
Day 31-35: 4B/5A（抽象形容词、动词短语、学科用语）
Day 36-40: 5A 预习（职业、家庭关系、学术词）
```

## 短文撰写规范

每篇 200-350 词，当天 10 个生词自然嵌入。

写法要点：
- **主角固定**：Tom（男孩，10岁，喜欢运动）——让佳乐有代入感
- **主题贴近**：学校生活、家庭、运动、动物、旅行——佳乐的兴趣领域
- **生词标红**（家长版用 `【word】` 包裹）
- **语法简单**：以简单句为主，偶尔复合句
- **有故事性**：不是词表罗列，是真正的叙事

示例结构：
```
Day N 标题 → 故事正文（含10个生词）→ 读后3题 → 艾宾浩斯复习提示
```

## 读后小测

3 种轮换题型，每 3 天循环：
1. 人物/大意型：短文里有几个人物？讲了一件什么事？找出5个今天学的单词抄下来。
2. 地点/句子型：发生在什么地方？最喜欢哪句话？用两个单词造句。
3. 圈词/结尾型：圈出所有今天学的单词。最后发生了什么？给短文起个标题。

## DOCX 输出

两个文件：
- `佳乐英语每日单词-学生卷.docx` — 词表 + 短文 + 题 + 艾宾浩斯
- `佳乐英语每日单词-家长答案.docx` — 同上 + 答案标注 + 短文生词标红

排版参数：微软雅黑，正文 11pt，标题 14pt，单词表蓝色加粗 11pt，页边距 2cm。

Python 依赖：`python-docx`

## 艾宾浩斯复习

每天短文后附复习提示，间隔：D+1, D+3, D+7, D+15, D+30。
```
🔁 艾宾浩斯复习提示（今天还需要复习这些词）
  D+1回顾：word1 · word2 · word3...
  D+3回顾：word4 · word5...
```
家长口头抽测即可，不占书写时间。

## Vision 工具注意事项

- DeepSeek 不支持 vision，Hermes 用 Ollama(Windows, minicpm-v:8b) 后备
- 手机拍 JPG（~200KB）成功率约 30-50%
- 缩小到 ~25KB/500px 宽 → 成功率 ~50%（非60%，2026-06-27实测）
- PDF 需先 `fitz.open()` → `page.get_pixmap()` → 保存 PNG，但转图后基本全失败
- 采样关键页即可，不必逐页——Vision 批量不可靠，单张碰运气
- 如果采样 3-4 张能确认规律，直接基于规律+词表生成，不等识别完

## 集成到暑假练习（2026-06-27 完成）

生成独立的每日单词 DOCX 后，需替换暑假练习中的英语阅读板块：

1. 生成 40 个新阅读文件（词表+短文+题）→ 写入 `英语新内容/03-阅读v3/`
2. 重新运行合并脚本，将所有 DayXX-全部练习.docx 中的英语阅读替换为新版
3. 艾宾浩斯复习提示嵌入到合并后的英语阅读板块末尾
4. 家长答案版同步更新

⚠️ **WSL 复制陷阱：** `shutil.copy2` 从 /tmp/ 到 /mnt/c/ 可能静默失败。
用 Python 循环逐文件复制 + try/except，不要用 bash `cp`（08/09 八进制问题）。
复制后必须抽样验证（Day01/Day20/Day40），确认新短文已生效、旧短文已消失。
