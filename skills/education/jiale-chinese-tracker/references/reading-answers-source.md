# 佳乐阅读理解答案源与合并流程

## 答案文件位置

阅读理解完整答案（含短文原文+逐题详解）分布在两处：

### 1. 已合并版（推荐直接使用）
- **路径**: `C:\Users\admin\Desktop\佳乐语文阅读理解答案汇总.docx`
- **内容**: 40天全部答案，按暑假 Day02~Day41 顺序排列
- **格式**: 每天标注"Day XX" + 来源练习天数
- **用途**: 打印出来，佳乐每天做完一篇后翻到对应 Day 核对

### 2. 原始源文件
- **路径**: `C:\Users\admin\Desktop\reading-practice-60days-docx\家长答案\`
- **格式**: `第X天-答案与指导.docx`（X=1~60）
- **内容**: 60天独立文件，每文件含：
  - 短文原文（1-2篇）
  - 完整题目
  - 详细答案解析
  - 家长批改指导

## 映射关系

暑假练习（Day02-Day41）的阅读理解文章并非按 1:1 对应阅读练习（第1-第60天）。文章标题部分直接匹配，需通过模糊匹配建立映射。

### 建立映射的方法

1. 从暑假学生卷提取每天的阅读文章标题（在`《》`中）
2. 从阅读练习答案文件中搜索文章标题关键词
3. 逐篇评分匹配（精确匹配 10 分，部分词匹配 3 分）
4. 阈值 ≥5 分即视为匹配成功

### 特殊情况

- 部分相邻天共享同一篇文章（如 Day05/Day06 都做《蚂蚁搬家的秘密》）
- Day38 是组合短文（《美丽的晚霞》《哪吒闹海》《蜡烛和台灯》），仅第18天含《蜡烛》，手动指定

## 重新合并流程

若原始文件有更新需要重新生成汇总：

```bash
python3 merge_reading_final.py
```

脚本核心逻辑：
1. 读取所有 60 个练习答案文件，建立全文索引
2. 读取 40 个暑假练习文件，提取阅读文章标题
3. 为每个暑假天找最佳匹配的练习天（关键词评分）
4. 按暑假天顺序输出合并 DOCX，保留原始格式

## 注意事项

- 合并后文件 ~480KB，约 80-100 页（含短文原文）
- 打印建议：双面打印，黑白即可
- 若文章内容有调整，需重新运行合并脚本
- 60 天练习中有部分天未被任何暑假天引用，为备用材料
