| 古诗积累 | 10分 | 奇数天（20首四~五必背） |

## 诊断规则

- <50分：四上基础需大量补，重点看拼音写词语+字音字形
- 50-70分：有短板，看哪个板块得分最低
- >70分：基础较好，重点补阅读+古诗

## 工作流

### 步骤1：家长打印检测表 → 佳乐做（分2次，各45分钟）

检测表含8大板块100分。不强求一次做完，不提示答案——这是摸底。

### 步骤2：家长对照《家长指南》批改

指南中有标准答案+评分标准+诊断对照表。

### 步骤3：确定薄弱板块

根据各板块得分，找到得分最低的2-3个板块。

### 步骤4：对照暑假练习

| 薄弱板块 | 暑假对应练习天 |
|---------|-------------|
| 看拼音写词语弱 | Day 1,6,11,16,21,26,31,36 |
| 字音字形弱 | Day 2,7,12,17,22,27,32,37 |
| 成语弱 | Day 3,8,13,18,23,28,33,38 + 偶数天成语背诵 |
| 修改语段/句式弱 | Day 4,9,14,19,24,29,34,39 |
| 说明方法弱 | Day 5,10,15,20,25,30,35,40 |
| 阅读弱 | 每日阅读（重点分配说明文/非连） |
| 古诗弱 | 奇数天古诗背诵 |

## 诊断结果 → 暑假练习生成

诊断结果直接驱动 `jiale-summer-practice` 技能的练习生成策略：

| 诊断结果 | 练习策略 |
|----------|----------|
| 字词大面积❌（看拼音写词语+字音字形<50%得分） | 字词频次从5天扩到20天（隔天），砍成语/古诗让位 |
| 阅读大面积❌ | 保留40天80篇，前20天降低短文难度（250-350字） |
| 写作薄弱 | 当前40天练习中写作输出为0（只有晨读范文输入），需额外补充 |
| 个别板块薄弱 | 仅调整该板块频次 |

佳乐当前诊断结果：字词和阅读是不及格主因 → 字词频次大幅增加，成语/古诗/作文晨读削减让位。

**铁律：字词是阅读和写作的基础。字词大面积空白时，成语和古诗必须让位给字词。不要同时抓七八个板块。**

### 步骤5：暑假结束复测

用同一份检测卷再做一次，对比进步。
