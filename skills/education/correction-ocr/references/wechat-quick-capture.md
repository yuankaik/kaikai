# 微信快速采集（Vision 预分析中转）

## 场景

用户通过微信直接发送练习题/试卷照片时，微信平台会预先对图片进行 vision 分析，
将结构化文字描述注入到消息中（格式：`[The user sent an image~ Here's what I can see: ...]`）。

## 快捷路径

```
微信拍照 → 微信平台预分析 → Agent 直接读取 → 结构化呈现 → 保存
```

**跳过：** vision_analyze 调用、Pix2Text OCR、Tesseract

## 何时使用

- 图片通过微信平台传入且消息中已包含 vision 分析结果
- 图片是普通练习题（非红笔订正、非✅❌检测表）——如填空、算术、词汇表
- 用户只是要做记录归档（非正式检测追踪）

## 何时不用

- 需要精确识别 ✅❌ 标记的正式检测表 → 走 `jiale-math-tracker` 等专用技能
- 红笔批改/订正本 → 需要区分红黑文字，微信预分析可能丢失颜色信息
- 微信预分析结果明显不完整或错误

## 保存目录

快速采集临时存 `~/错题/`，文件名格式：`YYYYMMDD_HHMM_科目描述.txt/.jpg`。

正式检测结果仍走 `/mnt/c/Users/admin/Desktop/shanghai-exams/` 的 JSON 追踪体系。

## 2026-06 实际验证

会话中测试了 4 张图片（英语词汇、语文拼音、数学综合、数学加减），
微信预分析结果准确度足够用于快速归档，无需额外 OCR。
