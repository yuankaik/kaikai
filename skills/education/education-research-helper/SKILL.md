# 教育研究助手：调研 + 匹配 + 抽查

## 触发条件
- 用户要求搜索教育相关内容（学习习惯、知识点、教辅评估）
- 用户要求分析练习材料与课标的匹配度
- 用户要求生成抽查题目
- 用户讨论佳乐的学习方案调整
- **用户询问升学路径/政策：某区有没有 XX 对口初中、哪所学校收特长生、**
  **要不要走体育/艺术特长、某区学籍规则** → 走"升学路径调研"章节
- **用户给一个成绩问"算什么水平"**（游泳、田径、任何竞赛项目） → 走"成绩水平评估"章节
- **用户拿着获奖证书问"附近哪里能培训/拿去问问看训练"** → 走"培训机构/场馆调研"章节
  （答案优先区少体校，不是商业机构）

## 三平台用法（必须交叉使用）

| 平台 | 擅长 | 不适合 |
|------|------|------|
| 小红书 | 育儿实操、习惯养成、妈妈经验 | 学术深度、课标细节 |
| 知乎 | 深度长文、认知心理学、学习方法论 | 时效性内容 |
| 微博 | 实时热点、教育新闻 | 系统知识 |

⚠️ 用户反馈："知乎好像你搜索的很少，还有微博"——不能只盯小红书。三平台必须交叉验证。

**注意：钓鱼、乡村民宿等极度细分的农村内容，三平台都搜不到。不要重复搜索，直接告知用户。**

## 核心原则（来自佳乐系统铁律）

1. **动作越少越能坚持**：设计方案时，新增习惯不超过 2 个
2. **寄生原则**：新习惯要挂在旧习惯上（如"口算 + 晚间背诵"）
3. **不贪快**：习惯固化 66 天，21 天只是起点
4. **家长稳定性 > 一切**：晚间背诵的成功取决于家长是否每天在场
5. **数学定调（分阶段，别搞混）**：
   - **暑假** = 补基础计算，不要在小数/方程上加量。用户说"小数的计算无非是一个点迁移的事情"
   - **开学后（五上）** = **小数乘除法是最大扣分项**，必须给足每日计算权重；简易方程跟老师走
   - ⚠️ 这两条不矛盾，别把暑假的"不加量"误用到开学后。详见 `references/shanghai-grade5-benchmarks.md`
6. **拒绝刷卷**：佳乐对卷子抵触，不做金试卷/一课一练。用周抽查替代
7. **睡眠是最高杠杆项**：判断标准是**关灯时间**不是上床时间。入睡潜伏期 >30min 是问题信号（不是"还没适应"）。学业量够了之后，改善入睡比加学习量收益高得多
8. **周六不愿意做事是正常需求**：成熟答案是"周六留白 + 周日恢复"，不是周六补作业。别把孩子的正常需求当问题去"解决"

## 周抽查流程（Hermes 协助）

```
周六/日  爸爸拍照发来（作业/课本）
        ↓
Hermes  识别错题 → 找薄弱点 → 出 3-5 道题
        ↓
周日    爸爸口头问 15 分钟（不写字）
        ↓
讲清楚 → 过 | 讲不清 → 补同类题，下周查
```

题目特点：
- 口头回答，不写字
- 数学：讲步骤思路
- 语文：辨字 + 造句
- 英语：改错 + 讲语法规则 + 口语变式
- 时长：三科合计 15 分钟

如果作业本被学校收走 → 拍课本目录/单元标题，从知识点出题。

## 课程匹配分析流程

当用户问"暑假练习覆盖了五上多少知识点"：
1. 先读练习材料（全部 40 天），统计题型分布
2. 对比该年级课标知识点
3. 输出匹配度百分比 + 缺口清单
4. 缺口按"是否需要立刻补"分两类：硬缺口（计算相关）vs 软缺口（考前突击即可）

## 自驱力理论（知乎 971 赞核心）

反馈闭环模型：学习 → 发现卡点 → 当场解决 → 成就感 → 更想学

普娃四大坑（佳乐中前两个）：假装努力、不懂求助、依赖奖励、全靠监督

关键认知："对小孩来说，成功才是成功之母。带他赢一次，方法论就会自己复制。"

## 语言问题处理

10 岁极端语言 = 前青春期"语言试枪"，不是品德问题。
- 冷处理：不接情绪钩子，用逻辑消解
- 给替代方案：同样释放情绪但不伤人的表达
- 区分"嘴里说的"和"心里想的"："爸知道你不是那样想的，但别人不知道"
- 时间：坚持 1-2 周频率下降，1 个月基本消失

## 家长配合习惯

以自身习惯带动孩子——父子同一张打卡表，互相督促。家长建议从 2 个开始：
- 早上不刷手机（起床后 30min）
- 睡前写 3 件事（2 分钟）

## 升学路径 / 政策调研（新轴，与学习资料调研同等重要）

kai哥会反复问佳乐的**升学路径**问题，不只是学习资料。已出现过的问法：
"XX区有游泳对口的初中吗"、"哪几所初中喜欢收这样的学生"、"XX成绩算什么水平"。
这类问题的调研有固定套路，**先查政策再查学校**，否则会浪费大量搜索。

### 铁律：上海小升初没有特长生通道（2020 年起）
上海市教委 2020-03-11《关于2020年本市义务教育阶段学校招生入学工作的实施意见》：
**"全面取消各类特长生招生，包括初中的体育、艺术特长生。"** 政策延续至今。

推论（直接回答整类问题）：
- 不存在"某项目对口初中"这种招生口径 → "哪所初中喜欢收 XX 特长生"**无答案**
- 公办初中只有：学籍对口 / 户籍对口 / 电脑派位；民办初中：摇号
- 特长生的真通道在**初升高**：市重点+特色高中的"市级优秀体育学生"招生计划，
  报名资格门槛 = **初中阶段区级（与招生学校项目对口）比赛个人项目第 1 名**
- 所以任何"为了小升初让孩子练 XX"的路径都不存在，要直接点破，别顺着用户设想推演

⚠️ 不要在没有政策依据时假装"某校偏爱特长生"。先查政策，再查学校，最后给结论。

### 成绩水平评估方法（通用）
用户问"XX 成绩算什么水平"时，三步：
1. **换成标准距离**：25 米成绩含单次出发优势（跳水+水下腿），天然虚高。
   折算 50 米 ≈ 25米成绩 × 2 + 3~5 秒（后程掉速+转身）。这是最容易出错的地方。
2. **放进同龄组区间**：查该地区该年龄组的商业赛/锦标赛实测区间（见 reference）
3. **分层定位**，并明确指出"上限（长训尖子）vs 常态化训练 vs 强身健体"三条线

必须点破的三件事：
- 短距离成绩会掩盖耐力型孩子的真实优势（先看孩子强项是爆发还是耐力）
- 参照系选错会误导判断（"全校第一" vs "全市育苗杯"是两个量级）
- 区分"业余上游"和"竞技苗子"——前者已跑赢绝大多数同龄人，不必贬低

### 特长生路径的成本（必须如实告知，不要美化）
知乎高赞（19 赞）描述的真实强度：二级运动员一般练到初中；
三年级以上一年 365 天只休过年几天；周末一天两练；暑假一天两练甚至三练。
**"上初中按这个训练强度，读书基本上不存在的"**，初一就开始选市队省队，
选不进→半训练半读书，运动生涯到头；选进→合同制 1-3 年，练不出来退队回少体校，
"可能面临连考高中的机会都没有"。
上海每年同济、交大、华师大、海事招的游泳队加起来也就几个人。

给建议时的框架（三条件缺一不可）：
1. 孩子本人愿不愿意 2. 成绩能不能拿区级第一 3. 家庭能不能接受"读书基本放弃"

### 学籍卡点（徐汇类问题必问）
徐汇：**小学同区不能转学、跨区可以转**；部分初中要求"小学学籍在徐汇满三年"。
所以讨论某区升学路径前，**先确认孩子户口/学籍现在在哪个区**——否则整条路从学籍上就断了。

## 培训机构 / 场馆调研（新轴）

kai哥会拿佳乐的获奖证书问"附近哪里能培训、拿去问问看训练"。这类问题的正确答案
几乎**永远不是商业培训机构的"长训班"**，而是**区少体校**。别一上来就搜"游泳培训机构"。

### 铁律：优先少体校，不是商业机构
- 区少体校（青少年体育运动学校）= **体制内竞技通道**，区体育局直属，走"区队→市队"
  正式通道；长期训练**费用由学校承担（免费）**；未来"区级第1名→初升高市级优秀体育学生"
  的路只有从这里走
- 商业培训机构 = **消费通道**（"包教会"），对已有比赛成绩的孩子"喂不饱"，练不出竞技成绩
- 已有区级比赛名次的水平 → 直接建议**带证书去少体校面试/进区队**，不要买商业课包

### 少体校招生的两个关键事实
1. **选拔制**，不是交钱就能进：看身材条件、四肢比例、协调性、运动潜质。孩子的
   区级比赛名次是硬通货，面试时直接出示证书
2. **游泳项目通常单独招生**，不在每年 3 月那批"大名单"里（那批多是排球/乒乓/羽毛球/
   网球/体操/击剑/射击等）。游泳的时间点一般是：幼儿班 3-4 月、暑期班 6 月

### 调研流程（政府官网是唯一权威源）
1. 先定位用户给的地名坐标（小区名 → 街道/路号，搜狗/百度中文地址搜索，见 `cn-local-info-search`）
2. 搜 `<区> 少体校 游泳 招生简章` / `<区> 青少年体育运动学校 游泳 招生` →
   **命中各区人民政府官网（shhk.gov.cn 等）的招生简章**
3. 抓简章正文：地址、电话、收费、招生对象、报名时间——这些只有官方简章才准
4. 区属场馆（如"百年泳池"）也一并列出，作为备选
5. 输出**按优先级排序 + 带电话 + 带"该问教练什么"清单**，方便 kai哥直接打电话

### 政府官网正文抓取的坑（实测）
- `<区>人民政府官网`（如 www.shhk.gov.cn）**请求可以直连抓到正文**，不用浏览器
  （浏览器反而超时）。正文在 `关闭】` 标记之后，用 `txt.find('关闭】')` 定位再切段
- 百度结果 URL 是 `baidu.php?url=` / `link?url=` 跳转，要跟一次 301 拿真实
  `shhk.gov.cn/...html` 地址（requests `allow_redirects=True` 即可）
- 详细发现（虹口少体校/虹口游泳池的地址电话收费、二次验证路径）见
  `references/shanghai-youth-sports-training.md`

## 长任务交付规范（kai哥"综合分析"类请求）

当用户说"综合分析一下，作为长任务交付，不追求速度追求质量"时，固定套路：

1. **GitHub 搜技能库并真的应用**（用 `skill-discovery` 技能的关键词直搜 + codeload zip），在交付物里标注用了哪几个 skill 及其循证依据
2. **多平台爬取**（用 `cn-scraper-mcp`），知乎是主力，其他平台补
3. **交叉验证**：同一结论至少 2 个来源；标注赞数作为可信度信号
4. **逐条点评用户现有方案**（哪些对/哪些要改/为什么），不是另起炉灶给新方案
5. **直接指出用户的认知错误**（如数学重心记错），不粉饰
6. **交付**：桌面 PDF + MD 双份（`/mnt/c/Users/admin/Desktop/`），weasyprint 生成 PDF
7. **诚实汇报平台状态**：哪个没抓到最后、为什么、怎么恢复——不要假装全绿
